Clang removes the mere declaration-to-declaration temporary copies. The default offset still uses the optional-argument ABI and spills across the character call; shape dispatch and loads survive, and the high-surrogate branch re-reads fields across the call. Those character reads and read-side field lowerings remain outside this store authorization. Go's char uses integer offsets and a direct byte load with a bounds path; its Unicode decoding is separate. This is the corresponding scanner work, not literally identical source semantics: Adamic code returns a UTF-16-aware code point while Go char first returns a byte. Go Scan inlines char and uses an indexed jump table after a range check; the native punctuation C contains a floating-point comparison chain. The observed temporary declarations are not assigned fictitious instruction costs.

Implementation:
SetProperty retains its existing undefined-object check after RHS evaluation. writeFieldSlot guards check_write with object->frozen for public names, omitting it for #private internal slots exactly as the runtime does. Ordinary objects use fieldSlot. Programs containing static layouts retain the runtime class/is_static distinction even through structural views, calling write_field only for a static object. The old reference is saved, the new value is retained or transferred into the slot, and only then is the old pointer released. That ownership lowering is unchanged.
