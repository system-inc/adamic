Implementation and boundaries
emit_speed.go emits content-deduplicated static ADAMIC_COLD _Noreturn helpers. Generated cast, unwrap, TDZ and array-shrink stops share a helper per exact message. Field stores combine the existing null and public frozen conditions into one cold call per property; private names remain exempt from frozen checks. Evaluation order and retain-new/store/release-old order are unchanged, including aliasing. No names or temporary/cache counter allocation mechanisms changed.
Invalid scalar-array writes share adamic_array_write_failure, preserving runtime formatting and exit status. Existing runtime panic, stack overflow and unreachable declarations are cold/noinline. Standard array allocation failures and three allocator-entry failures call adamic_out_of_memory. Allocation-failure bodies were explicitly authorized by this unit; destruction-side allocation paths, retain/release, character reads and field-read plumbing were not edited. Existing dynamic-message panic and checkDefined sites still call the shared cold panic function; not every message setup is deduplicated. No checks were elided and no source switches were changed. Object layout is unchanged.
