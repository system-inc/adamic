Implementation
- The int32 cast has one magnitude comparison. INT32_MIN and values through 2^53
  use a guarded int64 cast; C's unsigned conversion gives the low 32 bits.
  In-range fractions also truncate correctly through the cast. Other numbers use
  the original trunc/fmod conversion. No out-of-range or nonfinite cast is allowed.
- Remainder checks both ranges, a nonzero divisor and integer round trips before
  int64 remainder. A zero result uses the dividend's sign via copysign. Fractions,
  nonfinite numbers, zero divisors and magnitudes greater than 2^53 still use fmod.
- Pure, directly nested bitwise expressions stay in uint32. The final number is
  signed except for >>>. Calls keep the original expression evaluation path.
  Ordinary numeric locals remain doubles; no inter-statement range analysis.
- counts.md is byte-for-byte unchanged. The new .a fixture has a separate
  differential test rather than a new row in that table. All existing rows were checked.

Observations and limits
- Before: adamic_bitwise_and calls trunc and fmod for each finite operand. The
  final target loop uses guarded casts and does not take the slow helper branch.
- The new remainder helper changes clang's inlining of sort's next function.
  Both main eight-benchmark runs showed a small sort slowdown (4-5%). A separate
  three-run follow-up measured main 0.2296s, unchanged final 0.2235s (2.7% faster).
  A standard C inline hint restored inlining but did not consistently improve
  times; a branch-free copysign variant slowed the target remainder loop. Neither
  experimental change is in the implementation. Raw trials are retained.
- spectral_norm, nbody and trees have identical generated C before and after.
  spectral_norm's small difference changed direction between the two full runs.
- These short-program differences overlap measured run-to-run variation. The
  strict no-regression bar cannot be certified here; do not treat the large target
  gains as proof that every program gets faster. No correctness or allocation
  regression was observed. Other architectures were not measured.
