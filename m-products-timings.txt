# Product measurements

Base: origin/main a467d1a1571c43e0f01fc4efcb43890280e4a1ac, fetched at the start. Instance CPU quota: 400000/100000 = 4 CPUs; 16 GiB memory. Go 1.27.1. All measured products ran serially, one exact top-level selection per process, -count=1 -v -timeout 90s. The current 90-second rule overrides the earlier requested 10m. No whole-package tests ran.

## Go compilation

`go test -c -o /dev/null` walls: lint 160.834 s, tsprinter 8.064 s, markdownblocks 6.492 s. One initially empty GOCACHE, in that order; later packages reuse common Go compilation, so the last two are marginal package warm-up costs, not independently cold-Go costs. These are measurements on this instance, not arithmetic deductions from Loom's runs. The initial overlapping warm-up was discarded and all three repeated serially using a new empty cache.

Package compilation does not warm all overlay Go oracle/capture builds. Their first-use costs are retained below and fresh-product repeats distinguish them: DecodedOptionsNative first 80.617 s (Go oracle 45.54 s), repeated 30.959 s (Go oracle 3.75 s); NodeTableCapture first 67.669 s, repeated 12.904 s; statement Embedded_010's first Go oracle build 47.57 s, later fresh-product Go builds about 2–4 s. First statement attempts failed on npm's .bin/prettier symlink before Node ran; removing the install-only launcher preserved prettier@3.9.6 library bytes. Corrected fresh-product runs are reported.

Cold columns use a separate initially empty ADAMIC_BUILD_CACHE_DIR for every product. Dependencies-warm columns remove only that product's own entry, retaining its declared dependencies; all retain warm GOCACHE. Command walls include Go invocation/hash/registry overhead. Log phase times can overlap or nest and must not be summed indiscriminately.

## Dependencies and interpretation

CompilerAgreement native products use compiler-agreement-lowered (load/lower/C and JS emission). Their cold chain exceeds 60 s; sanitized cold chain hit 90 s. With that dependency built, native compilation is 11.20/34.00 s. These compiler costs belong to #3he8f8g.

DecodedOptionsNative's existing wrapper also prepares original and mutant lowering, its sanitized binary, Go oracle, and one fixture answer. NodeTableEmitted depends on NodeTableLowered; NodeTableNative depends on both. Capture has no separately declared prerequisite but runs overlay upstream Go tests.

ProfileCompilationC depends on ProfileCompilationLowered. Counted and Scanner also fetch C and JavaScript emission. OracleOutputs prepares scanner, counted and profiled binaries plus the Go oracle before its answer product (0.04 s). Their excessive cold walls are compiler work, not oracle-answer work.

ShardsAgreeNative depends on ShardsAgreeLowered (one combined load/lower/C-emission recipe). ShardsAgreePrepared depends on lowered, native, Go oracle, capture and generated/recovery fixtures. Its first dependency-warm retry still built oracle and capture and took 28.50 s; the all-dependencies-built result is in the table. The cold chain hit 90 s during oracle compilation after 73.93 s lowering/emission and 9.97 s clang.

JSX setup uses jsx-membership, jsx-parser, jsx-tree-lowered and jsx-tree-native and captures/copies fixtures. Statement library products depend on TSPrinterGoOracle and TSPrinterStatementsCorpus (935 files, 58052 supported fragments), then run their own npm or embedded Node oracle. MutantNative_020 has no separately cached lowering prerequisite: its own recipe logs lowering, C emission and sanitized clang.

MarkdownWhitespace_manifest prepares list and policy lowering/emission, Go lists/layout oracles, release and sanitized list binaries, and a sanitized policy binary, with concurrent recipes. Combined lowering/emission logged 36.80 s (list) and 23.48 s (policy); policy clang 27.30 s, list sanitized clang 20.28 s and release 10.24 s. The aggregate setup took 62.54 s; manifest rebuild with all dependencies retained is below 60 s. No instrumentation was added, so inseparable lowering versus emission cannot be assigned finer timings.

No measured product exceeded 60 s with a dominant qualifying own-work phase once transitive Go compilation was warm. No test source changed; no split, union/failure proof, lane-check or PR was required. No merge performed. Compiler emission/clang excesses are named above, not worked around. Two full cold chains remain failures under the 90 s rule and are reported honestly.

Raw evidence and drivers are saved in m-products-measurements.txt on the WIP branch. The scratch branch must not be landed.
