# String third slice implementation

The claim is 63d737a. The starting tip is e911e46; de0c4e9 merges regex-protocol ffb3ae0 after reading its implementation and handoff. String methods reuse that branch's RegExpCall, matcher, protocol runtime, replacement callback collection, iterator behavior and builtin error identity. No second protocol or matcher is implemented here.

`library_string_box.go` constructs a private String payload inside an object. The admitted observations are object identity, typeof, UTF-16 length and numeric indexing, intrinsic primitive conversion, typed String methods and literal-key hasOwnProperty. The string is captured once. Fractional numeric keys are absent; canonical decimal string keys are supported. The private slot is never observable as an own property. Unknown producers, reflective enumeration, spreads, destructuring, erased or prototype views, and prototype mutation are refused. The guard follows nested fields and collection element types, with cycle detection, so a wrapper cannot erase the box's representation. Primitive strings assigned a structural String view are refused as well.

`library_string_regex.go` factors the existing RegExp argument admission out of regexBuiltin, then routes primitive, boxed and explicit String.prototype.method.call receivers through that same dispatch. Supported methods are match, matchAll, replace, replaceAll, search and split. Callbacks retain the protocol unit's zero/one parameter proof and collection-before-callback behavior. A custom receiver conversion is admitted for global-validation methods only when the RegExp is proven global, preserving the order of validation and observable ToPrimitive. Constant primitive match/search patterns reuse a factored regexCompiled helper. Dynamic patterns, hooks, exec overrides, species, getters and richer callback signatures retain explicit refusals. Some default or string-pattern calls are rejected by TypeScript's declarations; those are not work owed.

`library_string_ranges.go` ports V8's StringFromCodePoint and StringPrototypeRepeat checks into cleanup-aware IR throws. Every scalar argument is evaluated before validation. Errors carry the imported runtime's real builtin constructor identity. Code points reject nonintegers, negatives and values above 0x10ffff. Repeat truncates count, handles NaN and negative zero, and checks V8's maximum length before allocating. Its RangeError message formats the original count, including -1.5. Spread argument stack limits remain refused around try. The Validated IR markers identify calls dominated by those guards; native runtime checks remain present. The V8 files are named in THIRD_PARTY_NOTICES.md.

The previous synthetic String TypeErrors now use the shared builtin error representation. The shared exception reachability walk accepts validated String operations while retaining conservative checks for unchecked spread calls. One obsolete shared lower test requiring repeat in try to refuse was removed; independent .a fixtures now check its RangeError, transitive reachability and finally behavior.

No changes were made to internal/native/emit.go, internal/lower/lower.go, internal/native/native.go or internal/oracle/oracle_test.go. No new runtime algorithm was needed. The assertion prelude and error identity implementation come from the requested RegExp dependency. Locale-sensitive casing/collation remain refused: Node uses ICU 78.3 here, while pkg-config finds neither icu-uc nor icu-i18n. A host libc or ordinal substitute would not establish Node agreement. Hidden object conversion members also remain refused without an exact view proof.
