## Scope and dependencies

V2 selects complete mixed primitive and object/primitive members, preserves the selected object contract through subsequent reads, selects untagged plain object alternatives without a fabricated entry tag, and preserves checked tuple identity, arity and positional contracts. Unknown provenance retains checks. Presence, initialized state, actual logical kind and null/undefined separation come from V1. No second readiness table or allocation solver is permitted.

The lane commits contain changes belonging to later slices. A full replay would therefore violate the requested V2 boundary. The real restack must separate these portions before compiler admission:

* dca0b478e introduces primitive array-index read support. e3be8faf5 adds homogeneous array-union projection support. Tuple-specific storage and positional reads are V2; general checked array admission remains V3.
* f426929a0 combines recursive union completion, semantic undefined handling and callable union admission. 8de074ccb adds nested callable producer certification, including the protected lower.go state field untaggedCallableTargets. cd32db423 combines recursive array completion with callable mismatch repairs. Their callable admissions are V4. Preserve recursive object checks separately; do not copy callable builders or clear their unsupported descriptors to make V2 fixtures pass. If that separation cannot preserve the required recursive-object checks on V1, stop and name the exact dependent hunk.
* c41eaf85f adds primitive/nullish dictionary reads. 8ccad7e19 imports seven intersection certificates. fc253f975 and e286a95d9 depend on intersection descendant support. Keep new dictionary and non-phantom intersection admission in V5. A V2 union can retain an unsupported descendant obligation; it cannot call that obligation proved.
* cf1765d11 combines optional tuple arity with optional tuple-valued Map checks. 3dd953f75 combines rest tuple reads with complete Map rest-schema checks. Keep the single tupleViewSlot constructor. Determine from V1 whether the existing Map producer and schema path is already admitted; otherwise defer those Map positive fixtures instead of enabling another slice to pass them. No second tuple constructor or copied Map representation is allowed.
* f426929a0 adds a positive allocated recursive-cycle fixture. It is not evidence that V2 may admit cyclic ownership. Retain the existing cycle-capable refusal; runtime owns cyclic admission. Active-pair matching may be tested independently without changing source ownership admission.
* Primitive phantom carrier proofs are distinct from shape-check erasure. Retain only the already ruled __String/primitive proof available on V1. Do not import shape-conformance erasure from another lane. Read checks stay until their existing proof applies.

These are measured commit-content overlaps, not proof that every overlap is inseparable. A real-base implementation has not begun while V1 is absent. The late cross-slice commits cannot be cherry-picked unchanged into this unit.
