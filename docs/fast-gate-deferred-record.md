“Only it catches” is often an overstatement: a deferred mutant test proves an existing observation is sensitive, rather than supplying an otherwise absent observation. Rows distinguish that from a genuinely separate path. Coverage means eligible when the relevant package is selected by the fast gate, not a claim every landing executes every named test. Opt-in tests also need their inputs enabled; a skip is not coverage. The oracle fast lane runs the fixtures named in smoke.txt, not its whole corpus.

All times below are **unmeasured design estimates**, for warm tool/runtime caches, excluding Go package startup. No tests or mutants were executed for this document. Lint proposals assume one shared, freshly built candidate linter and oracle; building the full linter per smoke may exceed 15 seconds. Measure that prerequisite before accepting a seconds-long claim. Reusing a previous revision's binary is not acceptable. A small smoke covers representative mechanisms, never the exhaustive guarantees of the deferred sweep.

Rank is engineering judgment about the next broad lowering/IR/C/runtime/lint landing, not historical defect frequency. Each row includes its ranking rationale.

## Review boundaries

The largest unresolved budget is candidate linter/parser compilation. Choose a shared build arrangement before promising seconds-long end-to-end lint tests. The split smoke is already being built separately; this record does not duplicate it.

A qualifying mutation experiment must first pass the production smoke, apply one defect in an isolated copy/cache, show the intended observation failing, then restore green. Compilation failures prove compile-class smokes; semantic-class experiments should compile and fail at the claimed observation. No mutation experiment has been run here.

The two missing-on-base lint tests should be re-read after their implementation lands on the gate tools branch. The ledger names alone cannot establish coverage. The workspace implementations above make those rows useful for review without silently pretending the base contains them.
