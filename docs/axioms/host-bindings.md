# The host bindings, audited

A `.ts` file may declare a value the host supplies, as tsc does: `declare let onProfilerEvent` in performance.ts, `declare const process` in core.ts and again in tracing.ts, `declare const performance` in performanceCore.ts. docs/rulings.md refuses a program's `declare` of a value and trusts only Adamic's own declarations, each an axiom under Language's audit. Such a declaration is admitted only where the host-binding table names it, and the table is one of those axioms (ruled by @system_adamic on #00qn5az, Nov 5 and 6, 2026; the ledger's entry "A `.ts` file's ambient value declaration is a host binding"). This file is its audit, beside host-any.md, and Language reads every row before it lands.

The table is internal/load/host_bindings.json. TestHostBindingsAudit (internal/load/host_bindings_test.go) holds the rows below to it both ways, cell for cell, each row by its name and its declaration's file, and fails on a row with no ruling.

## What a row says

- **Declaration**: the file's basename, the keyword and the declared type's exact text. Only a top-level, unexported `declare` statement in a `.ts` file matches, every declarator of it a row's. Anything else stays refused as an ambient value declaration, and so does every `.a` file's, which is otherwise unchanged. A program's `declare const process: number` is never the row's. A row is its name and its file together, so a name a second file declares has a row of its own there, as process has in core.ts and in tracing.ts, and each declaration matches only its own file's row, by that row's keyword and type text. Two rows for one name in one file are refused.
- **Node**: what Node prints for `typeof` of the name, on the version named, running the declaring file as an ECMAScript module, as oracle/node.mjs runs every program. Under that module mode `typeof require` is "undefined", so core.ts's `declare const require: unknown` is a row, Absent on every target (@system_adamic on #baobab, Nov 8 2026): isNodeLikeSystem reads false natively as it does on the oracle's Node, agreement and not a fix, until 99q (#nqp4p7g) drops its `typeof require` test. The row matches only that declaration, by file and exact type text, so Node's own `require` elsewhere (sys.ts, #3sh9398) is never the row's. A build of another module format, `--module-format commonjs-bundle` (#redxes2), answers for itself: its answer joins a row as its own field beside this one, which never changes shape, and until it does, such a build stops at every row measured only in ES module mode, at its declaration and at every use (internal/lower/host_bindings.go, `hostBindingStopIn`).
- **native, javascript, wasm32**: Provided (the host defines the name, and reads go through its host model, never trusted), Absent (nothing defines it, and `typeof` answers "undefined"), or Pending with the owner who clears the column. Runtime clears the native column, and Runtime and Platforms clear the wasm32 one with it.
- **Model**: the host path a Provided row's reads route to, or the task that builds it while none is built.
- **Divergence**: a ruled backend divergence under which a column may differ from Node's answer, or none.
- **Ruling**: the ruling or task that made the row.

## What a row admits

Lowering makes one IR for every target, so a row lowers only when its three columns are equal and none is pending. Any other row is not yet, named, at its declaration and at every use (internal/lower/host_bindings.go, `hostBindingStopIn`).

An Absent row's `typeof` is the constant "undefined". The name itself is never read. A read is admitted only in the then-branch of `if`, the right of `&&` or the true arm of `?:`, under a guard `typeof X === "t"` with t not "undefined", or `typeof X !== "undefined"`, matched to the row's declaration by symbol. A shadowing local is judged as the local. Every other shape is not yet: `||`, an early return, a negated guard, a guard bound to a local, a guard in a called function. The guarded code is never lowered. It becomes a compiler-bug panic, reached only if the guard's test was wrong. A write to the name is refused, and so is a `globalThis.<name>` or `globalThis[name]` write naming any row, judged by the receiver's type, typeof globalThis, through any name for it: an alias, `globalThis.globalThis`, Node's `global`. Every other use of the global object as a value, an alias, an argument (Reflect.set, Object.assign, Object.defineProperty), a widening to `object`, `{}` or a record view, and the rest, is one not-yet, "the global object as a value" (internal/lower/global_object.go, #00qn5az head 3), pinned by TestGlobalObjectAsAValueIsNotYet; lifting any part of it has to answer the host-binding fold first.

Every column is held to Node's real `typeof` by internal/oracle/host_bindings_test.go, whether or not the row lowers: Absent where Node prints anything but "undefined" fails, and so does Provided where Node prints "undefined", unless the row names a ruled divergence.

## Changing a row

A row changes here and in the JSON together, with the ruling that changed it. A column moves off Pending only when its owner clears it on #00qn5az or a task that names this file. A Provided column's model has to exist before its row lowers.
