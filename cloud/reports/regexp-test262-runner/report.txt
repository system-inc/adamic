Built
- Typed regExpUtils.js prelude: inclusive code-point range generation (10,000-point
  chunks), code-point diagnostic formatting, property/string-set checks with the
  original whole-input fast path and per-symbol/per-string fallback, and match
  validators checking every capture plus index and input. Missing optional fields
  become explicit undefined only for a fresh private helper argument.
- Nullable capture arrays can reach generic comparison helpers; undefined captures
  stay undefined. Checked unwraps retain a runtime null/undefined check. No casts
  assert that a match exists. Expected metadata arrays become private records only
  after ruling out aliases, escapes and unsupported writes.
- Constant string constructors accept unwritten let bindings. Writes in closures,
  assignments and loops prevent freezing a value. Known RegExp objects can be
  cloned with source/flags and lastIndex reset; RegExp(re) preserves identity.
  Omitted/intrinsic undefined patterns use the empty pattern. Evaluated arguments
  remain evaluated, and a flow-narrowed mutable undefined is never treated as a
  compile-time value. Undefined string concatenation is refused rather than
  incorrectly folded as an empty string.
- Discarded literals and new RegExp constructions lower as evaluations. Literal
  patterns rejected only by the older TypeScript regex validator are rewritten
  to equivalent constant constructors under an unmodified intrinsic RegExp;
  Adamic's current parser remains authoritative for the pattern grammar.
- Removed blanket regex-feature skips. Unsupported reflection/Symbol semantics
  still skip; invalid constructors that need runtime SyntaxError now loudly refuse
  rather than appear as compiler crashes.
- Independent original Node execution with real sta.js/assert.js/includes is a
  prerequisite for each RegExp pass. Adapted native and adapted Node are also
  compared, including exit status and stdout/stderr. Constructor-identity
  assert.throws tests refuse: the existing shared harness only checks ancestry,
  and independent Node success cannot establish a missing native assertion.
- Optional --jobs workers have private artifacts and ordered results. Serial,
  parallel, and attempted-test limits agree. Per-file results.jsonl records every
  outcome, reason and adaptation; --timeout bounds each native/Node execution.
