Incoming costs alone do not give separately recorded caller-specific taken counts. To avoid mistaking a mixture of NULL and counted values for all immortals, use the two-branch-per-call aggregate: for n calls, null z, immortal i, and counted c, the release boundary contributes z + 2i + 3c conditional branches. Descendants contribute nonnegative further branches. Equality to 2n implies c <= z, and hence i >= n - 2z. There are only 3,529 NULL releases in the entire profile. The selected set therefore contains at least 8,867,204 actual immortal outcomes (54.11%), well above both a majority and the 819,329-call 5% cutoff.
