Interface and assumption
------------------------
bash cloud/setup.sh --gate-inputs-no-archive
  Provides every existing gate input except ADAMIC_CLANG_TSGO_ARCHIVE and explicitly unsets that variable, even if an old archive remains installed.
bash cloud/setup.sh --gate-archive
  Provides only the archive among optional gate inputs. It clears the other optional gate variables. Ordinary worker toolchain, module, width dependencies and root build preparation still run. This interpretation is recorded in the implementation commit.
bash cloud/setup.sh --gate-inputs
  Retains all inputs including the archive.
Source the printed env.sh after every invocation. Conflicting archive-free/archive-requesting flags fail before preparation in either order. No new cache was added; the archive's existing Go build-ID key and output-byte checks remain intact, and ADAMIC_GATE_UNCACHED=1 retains its bypass.
