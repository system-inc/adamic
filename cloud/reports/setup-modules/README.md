# Module preparation proof

Added module dependency preparation to setup's submodule lane, after both Go and the recursive checkout are ready. It downloads and verifies all 20 module directories, including cohere's separate workspace and nested modules. It runs for ordinary setup and `--gate-inputs`; test-binary warming remains optional.

Base: `664a608d38aa62f09ffb88f76bc98c381f20ad3b`, fetched origin/area/developer-tools. Measurements used the same working-tree patch on that commit. This is an existing container with isolated, initially empty GOMODCACHE directories, not a newly provisioned VM. No container snapshot boundary is observable here.

The stamp covers each go.mod/go.sum and go.work/go.work.sum byte sequence (including absent versus empty), Go version, download-affecting Go environment, and helper source. Cached archives, module metadata and every extracted file are validated using path, mode, size, nanosecond mtime/ctime and inode. Missing/modified cache artifacts force download and verification. `ADAMIC_GATE_UNCACHED=1` always downloads/verifies. Workspace definition changes during preparation reject stamp publication. Go may generate workspace checksum files; those generated files are not committed in this cloud-only unit.

```sh
  -overlay=/tmp/adamic-gate/setup-modules-proof/overlay.json \
  -o /tmp/adamic-gate/setup-modules-proof/oracle-without \
  /workspace/adamic/cohere/adamic_lint_oracle.go
```

After `bash cloud/setup.sh --gate-inputs` with the prepared proof cache, that build exited 0 with zero stderr bytes. The three tests ran uncached:

```sh

GOMODCACHE=/tmp/adamic-gate/setup-modules-proof/with \
ADAMIC_GATE_UNCACHED=1 go test ./stage1/cohere/lint \
  -run '^(TestMutants|TestRulesAgree|TestCompilerAndStage1Agree)$' \
```

All passed: TestRulesAgree 32.37 s; TestCompilerAndStage1Agree 67.10 s (303 compiler files); TestMutants 232.10 s. Full output is in `lint.log`.
