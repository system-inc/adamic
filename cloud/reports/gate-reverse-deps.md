Partial implementation of devtools/gate-reverse-deps, cut from origin/devtools/fast-gate (89cbe74a).

run.py now reverses go list -deps -test -json ./..., including regular, internal-test and external-test imports, and takes the transitive closure from changed-file owners. Test variants use ForTest and synthetic test binaries are excluded. Existing embed and ancestor ownership remain. Compiler changes select the whole oracle and clear the existing deferred-test list so affected checks are not dropped to fit a budget.

The checked-in map is cloud/fast-gate/compiler-dependencies.json. Its format is a JSON object with version: 1 and packages: {repository-relative Go package directory: [repository-relative compiler package directories]}. Package-level declarations include every test and helper in that package. Dependencies are conservative across all seven compiler stages. The candidate's map is read first, with the tools checkout as a fallback for older candidates. Editing the map selects its declared packages. The census rejects unlisted Go package consumers matching compiler imports or known compiler invocation literals. Helpers under testdata belong to their nearest package.

This is not ready for canary promotion: stage 3 standalone and script driver dispatch is incomplete. Go compiler consumers outside an enumerated test package are recorded as compiler_consumers_without_test_package, not executed. Script sources and arbitrary indirect compiler invocations are not covered by the lexical census. Those gaps still need an execution contract and census coverage.

Mutants remove regular/test/external-test imports, transitive expansion, opaque dependencies, oracle widening, census rejection, map validation, deferred-test inclusion, ancestry, variant normalization, synthetic-binary exclusion and external-test ownership. git diff --check passed.
