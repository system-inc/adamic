cloud/node-pin.json records v24.19.0 and nodejs.org's published SHA-256 for Linux/macOS x64/arm64 .tar.gz releases. setup-node.py ignores every preexisting Node without its verified stamp. Its warm key includes version, checksum, OS, architecture, pin bytes and helper bytes; hits also validate executable bytes, mode and regular-file placement. ADAMIC_GATE_UNCACHED=1 reinstalls. Actual release binary and stamp are byte-identical cached and uncached (real-cache-proof.log).

Linux preparation remains parallel with Go, clang and submodules and retains gate/module/width/API preparation. setup-darwin.py runs before Linux shell facilities, providing Node and the same input helpers, warming and env exports using Python, Xcode clang and Go's automatic toolchain selection. It downloads Go if absent. It leaves shell configuration to the user, as 3ee1af9 requires. Python 3 is required. Linux is tested on this box; macOS asset selection and portable preparation flow are covered by tests, but no macOS machine or Mach-O execution was available.

internal/nodepin.Check uses the existing child deadline helper. The oracle TestMain, test262 entry point and fuzzer Prepare refuse any other version and name its path, actual version and required version.
