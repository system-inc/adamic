## Pick and implementation

I chose the CSS numeric adjustment sub-printer, which composes directly with the
quote slice as `adjustNumbers(adjustStrings(value, single))`. This is the actual
media-value/type printing path in Go cohere and Prettier. I read its whole
`print_misc.go` implementation and `css_units.go` table, and surveyed declaration
printing and its dependencies before editing. The earlier GraphQL and JSON slice
workflows, read in the previous unit, supply the oracle and gap discipline.

Full declaration printing delegates to child-value printing, printSequence and
the document layout engine; it also consumes AST paths, parent/source metadata,
nested declarations and template placeholders. Those dependencies are not
provided by the quote slice. Numeric adjustment is a complete text-to-text
boundary that can land independently of the CSS parser worker. No CSS parser,
compiler-owned file or previous quote implementation was edited.

`numbers.ts` implements the exact decimal/exponent matching grammar and greedy
word-prefix backtracking with finite scans. Recognized number/unit matches are
normalized, while quoted spans, unknown ASCII units and identifier-prefixed
matches retain their spelling. All 62 canonical units, including Q, Hz and kHz,
are captured from css-units-list 2.1.0. The normalization helper's domain is the
scanner's unsigned matched number grammar; this is not the arbitrary-input
printNumber utility API. That narrower domain permits a direct equivalent of
printNumber followed by printCssNumber, with no regex runtime.

The driver is a raw file-to-stdout sub-printer, with the prior escaped batch
protocol for comparisons and measurements. `GAPS.md` records the contract and
reproduction commands. LICENSE contains the Prettier and css-units-list notices.

## Throughput

The initial lookup lowercased/scanned every unit-table entry for each match,
including unitless numbers. The final lookup is the same table as constant
cases, with an empty-unit fast path and one lowercase operation. Parity and all
mutants were rerun after this change. The measurement ran with no other gate
competing for CPU. Each of three process runs handles the identical 89,786
cases, with startup, file input, escaping and output collection included and
compilation excluded. Native uses clang -O2 without sanitizers for timing.

| Side | Texts/s | Total seconds, three runs |
| --- | ---: | ---: |
| Go cohere | 511,771.1 | 0.526325 |
| Adamic native | 514,625.3 | 0.523406 |
| Adamic source on Node 24 | 236,847.5 | 1.137263 |
| Original Prettier 3.9.6 printer | 155,576.2 | 1.731357 |

Observed native throughput is about 3.31 times Prettier and 2.17 times Node
source. Native and Go are close in this short three-run sample; this is not
evidence of a reliable native-over-Go advantage. These are mixed-text
sub-printer measurements, not full CSS formatting or steady-state throughput.

## Delivery and exclusions

The branch contains the prior quote dependency, the new numeric implementation
and a report commit whose SHA is recorded in the final response. It is pushed as
`codex/stage1-css-numbers`; no pull request is opened. Both submodules are clean.

Full declarations, recursive value/layout printing, CSS parsing, arbitrary
standalone printNumber inputs, invalid UTF-8 byte preservation and non-Linux raw
stdout behavior are excluded. The driver relies on `/dev/stdout` because the
prelude has no raw stdout primitive. The corpus is evidence of agreement, not a
universal proof for all strings or all AST printer branches. See GAPS.md for the
exact grammar boundary and inherited proving program.
