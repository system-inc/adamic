# Fifteen-rule continuation

The subsequent performance follow-up is recorded in [PERFORMANCE.md](PERFORMANCE.md):
2.00 times native throughput, 59.50% fewer instructions, all output preserved.

Added fifteen syntax-only cohere rules on top of commit
`6636e8f16a932951458030c902cc3c502a6933e9`. The rule inventory and driver protocol
are in [README.md](README.md). All changes are in `stage1/cohere/lint/`.
Compiler, runtime, scanner, parser and submodule sources are unchanged.

The new rules cover control statements, destructuring targets, generator and
await ownership, declaration prefixes, label resolution, cooked strings,
operator options, comma chains, raw regex literals, BOMs, warning comments and
source-preserving ternary rewrites. Findings retain cohere's exact messages,
IDs, positions and repair categories. Finding and edit spans are distinct.
Repairs use deterministic overlap resolution, report rejected overlaps, and
reparse/re-lint between passes. Suggestions remain unapplied. Human output is
held to real `report.Write`; fixed output is held to real `edit.FixText`.

## Gaps and limits

Two new proving programs hold optional indexed access and numeric logical-or
lowering refusals to Node. Explicit guards/comparator branches are the
workarounds. The existing nested-constructor proof still holds. See
[GAPS.md](GAPS.md) and `validation/gaps.log`.

`no-shadow` and `no-redeclare` need the binder and declare `NeedsTypeChecker`;
they are excluded. No type/symbol checking, full config decoding/validation,
suppression, JSX, JSDoc node analysis or filesystem-writing integration is
claimed. Ordinary JSDoc block comments are included as comment trivia.

Five malformed no-div-regex cases compare findings and proposed edits only.
They print `recovery findings only`. Go's edit engine rejects invalid input
before collecting repairs, so no fixed-source claim is made for those cases.
General parser recovery/diagnostic parity and non-UTF-8 input remain outside
coverage. Overlapping edits are resolved and reported; invalid ranges,
nonprogress and exhausted native pass budgets stop explicitly rather than
silently returning a partial repair. General parse-refusal diagnostic parity
is not claimed.

Cohere's raw-source rule API retains BOMs; its live osvfs path strips them.
This oracle covers the raw-source API and real edit engine. The comment
collector also retains cohere's ASCII leading-trivia guard, including its
behavior on a comment behind a BOM.
