Choice and what was built

stage1/cohere/markdowninline ports word.go's contextual emphasis/strong escaping
and print.go's inline code, wiki links, image URL/title/alt, full/collapsed/shortcut
image references, label normalization and footnote reference printing. Its Unicode
punctuation classification comes from classes_generated.go. This boundary shares
string helpers and produces only strings/concatenations, so it needs neither a
parser nor recursive child/doc layout. YAML block/collection and full Markdown
printers require path/source state and doc layout. The full CSS declaration printer
requires recursive value printing and those same dependencies; its parser belongs
to the other worker. There were no compiler, parser or submodule modifications.

The driver formats the entire file as one selected leaf value. This is a leaf
printer suite, not a complete Markdown document formatter. Exported helpers take
separate URL/title/alt/sibling values. Word context booleans are facts a future AST
adapter must establish. GAPS.md gives the exact API boundary, all 19 driver modes,
reproduction commands and exclusions. main.ts writes raw bytes via /dev/stdout on
Linux and supports an escaped batch protocol for audit and timing.

The Go overlay calls the actual printMdast through real printing.AstPath stacks,
then doc.Print. The JavaScript adapter calls the original pinned plugin's mdast.print
and Prettier's doc printer. It supplies identical node and path facts, with no
substitute formatting algorithms. The pinned package was already installed from
the prior slice in /tmp/adamic-cssstrings-prettier/node_modules/prettier and reused
for final checks. This unit also installed the same exact version in the separate
/tmp/adamic-markdown-prettier scratch directory. Each library run asserts 3.9.6.

Observed corpus and verification

873 files were read physically, including initialized submodules, with case-insensitive
.md, .markdown, .mdown and .mkd suffixes and only .git directories excluded.
4,702 generated texts include the exhaustive 8-token alphabet through length four,
long values, malformed ends, NUL, quotes, whitespace, brackets, pipes, backticks,
astral endpoints and one combined text examining all 63,488 BMP scalars on both
sides of both delimiter kinds. All 5,575 texts ran through all 19 contexts, making
105,925 cases. The final escaped input was 84,924,870 bytes. Native under ASan/UBSan,
source Node, the JavaScript backend, Go and Prettier agreed byte for byte. A separate
LeakSanitizer pass and a raw stdout test for every repository/submodule file passed.
The persisted scratch corpus is /tmp/markdown-final-cases.txt; its .files.json sibling
is the complete file manifest. They are reproducible from the test.

Mutants (all lower, build, exit zero with empty stderr; no compiler refusal counts)

1. Escaped delimiter parity: invert odd/even backslash parity. Native and source Node
   both fail byte comparison at case 494, byte 3352, in mode w with
   cohere/TypeScript/tsc/CHANGES.md. The altered JSDoc enum escape has an extra slash.
2. Table pipe escaping: invert if(table). Both fail at case 6, byte 658, with CLAUDE.md
   as ordinary preserved inline code. Pipes incorrectly gain backslashes.
3. Minimum absent fence: prevent advancing past a present backtick-run length.
   Both fail at case 6, byte 1, with CLAUDE.md. The fence is one backtick instead of two.

The original regular-expression syntax is an executable gap, not a silent substitute:
gaps/1_delimiter_expression.ts prints a\*b on Node and raises lower.NotYet with exactly
"a RegularExpressionLiteral". TestDelimiterExpressionGap checks both observations.
The finite matcher implements this one original pattern's ordered alternatives,
greediness, backtracking, non-overlapping matches and UTF-16 semantics. The two
whitespace expressions are scans. No discrepancy in supported output was observed.

Timing interpretation

The final test runs three fresh processes per implementation. Input, decoding,
encoding, startup and captured output are included; builds are excluded. Every
timed output is compared to Go. Native uses native.Build's ordinary -O2 build,
not the sanitizer build. The original Prettier printer is measured directly.
The totals were Go 47.248539s, native 20.607544s, source Node 10.973133s and
Prettier 13.431816s. Native was about 2.29 times Go's measured rate, and slower than
both JavaScript implementations. These are observations on this mixed-size corpus,
including very large documents treated as single leaves, not a claim about full
Markdown formatting or steady-state small-token throughput. Other test processes
had finished before the timing phase.

Gate scope and limitations

The full gate was not repeated. The earlier full worker gate on this machine took
about 16 minutes; this unit edits only its new stage-1 folder. Ran its complete unit
checks, go vet ./..., gofmt over cmd/internal/the new folder, scoped cohere type/lint/
format checks (276 rules on the three production TS files), nine relevant uncached
runtime fixtures, the oracle's one-byte mutant and four output/file-order probes.
The native/Node observations in those oracle runs were cache misses. No counts or
compiler-owned files were edited. Integration's full uncached gate remains required
by CLAUDE.md before main moves.

Not covered: full Markdown parsing/layout, arbitrary AST adapters, MDX's legacy word
printer, invalid AST shapes including null wiki targets, isolated surrogate/invalid
UTF-8 file bytes, non-Linux raw stdout devices, all global oracle fixtures, YAML or
CSS declaration layout. The corpus tests whole files as leaf values; it does not
extract parsed Markdown nodes. No general regular-expression engine was added.
