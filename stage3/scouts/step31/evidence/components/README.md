Measured checker/emitter evidence for the second step31 delivery.

proof.json records both complete source-versus-stock passes and native_run=false.
benchmark.json contains every subprocess wall time and measured command.
The compressed goldens are the complete stable JSONL observations; compressed
manifests contain every input/output hash and per-project time. Requests and
cache shards are regenerated by run-components.sh from pinned selection files.

The cache-test producer programs are protocol test doubles. Their comparisons
prove format and independent stream checks; they are not native implementation
results. Actual TypeScript source mutants and their functions/edits/hashes are
recorded in source-mutants.json, with successful Node execution and empty stderr.
initial-reporter-failure.log preserves the fixed Unicode splitlines failure.
