## Minimal programs for @system_adamic_typescript

JSON itself has a static recursive domain. Primitive roots must remain observable; an object assertion is false:

```a
const parsed = JSON.parse("7");
console.log(typeof parsed); // number, including through readJson in tsc
```

Raw public config may contain invalid values. Existing list validation only checks that it is an array:

```a
const raw = { compilerOptions: { types: [{}] } };
// Preserve existing diagnostics/normalization; do not label types as string[] first.
```

A host handle can be correlated without a top type. Applying this requires the public owner contract:

```a
interface TimerHost<H> { start(callback: () => void): H; stop(handle: H): void; }
function roundTrip<H>(host: TimerHost<H>): void {
    const handle = host.start(() => {});
    host.stop(handle);
}
```

A staged header is not its completed node. Required parent and Type.symbol claims are false at allocation:

```a
class Header { flags = 0; parent: Header | undefined = undefined; }
const header = new Header();
console.log(header.parent); // undefined before any completion
```

An extension has its actual caller type and is copied unchanged:

```a
const source = { kind: 0, pluginField: new Date(1) };
const copy = { ...source };
console.log(copy.pluginField === source.pluginField);
```
