## Scope and partitions

This is first-error mode over the entry program's top-level independent units, as in the reused c13c98f7 tool. Generic declarations without a concrete caller are deferred. Callee bodies and generic instantiations reached by a unit contribute to that owner's lowering state. Nested functions are not added as independent full-mode units. Views recorded before an ordinary first stop remain observable in the unit snapshot; those are latent additional boundary findings in already blocked units, not claims that production reaches the boundary after an earlier error.

Every child loads the same tsc entry and resolved graph. Only outer unit enumeration is partitioned. The two heaviest files use disjoint AST position ranges, recorded in groups.json; registration, dependency bodies and prepasses still see the complete entry graph. File-level refusal scans repeated by a range split are checked for equality and counted once. Unit rows must be disjoint and coverage is checked on both sides. No file is compiled as a separate standalone program.

Each compiler process is capped at 1490 seconds, and each job supervisor runs only that bounded child. Each setup, build and control process also has an explicit shorter bound. run.py records the child's own exit status, elapsed time and wait4 peak RSS, and kills remaining child-group processes on exit. Job and compiler exits are distinguished. Interrupted attempts do not contribute final counts.

These are conditional unit-local boundary backstops in a graph program. They do not establish that the whole tsc program has graph membership, reaches this boundary, or is otherwise accepted. selected graph types, unplanned pair membership and other whole-program proofs are not modeled. No production regression claim exceeds this unit-local limit.
