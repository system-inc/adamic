# Declaration scheduling

The root declaration-plan/INDEX.json is immutable and shared by main and head.
It contains contiguous top-level source intervals and the complete full-mode
unit ownership beneath them. This preserves full mode and its nested declarations;
container-fit's first-error mode is not substituted for the posted measurements.

The 81-file Go catalogs agree exactly on 4,564 top-level statements and 10,721
full-mode units. An independent stock TypeScript inventory agrees on every unit's
identity, source byte span, top-level owner, parent and nesting depth. The four
already posted files are completed seed pieces, never rerun.

Run audit-declaration-plan.py for the complete partition audit and lost, duplicate
and moved-unit controls. It also checks that a contiguous refinement preserves
every original unit. audit-declaration-selector.py proves selection-off raw byte
identity to the original counter and meter on both compilers and exact selected
fixture unit/lowering-finding union. The IR counter source is unchanged.

New measurement pieces run main then head sequentially. Each pair, including
pairing, has a ten-minute limit. Raw files, timings, selection, plan digest and
status are archived and committed/pushed immediately. The first four posted
files retain their individual meter identity tests. New declaration chunks use
the proven selector and counter; they do not claim an additional original-meter
rerun on every chunk. Ordinary fields are stripped of only the three count fields
and passed to the existing pair tool with source roots canonicalized.

RESULTS.json records active immutable refinements. An interrupted parent cannot
run again. Its top-level interval is split between two contiguous children; no
unit may disappear, duplicate or move to a different top-level owner. If the
interval is one atomic top-level declaration, it is marked blocked. Neither
interrupted nor blocked observations contribute counts.

Execution order favors read-bearing smaller scopes, leaving giant atomic scopes
until they fit the remaining box budget. This ordering does not change assignment.
The conservative box stop is 17:04 UTC on 2026-11-06, leaving shutdown and push
reserve before this box reaches two hours. A fresh continuation must explicitly
record a new box budget; it must not silently alter the frozen source plan.

A fresh box can supply an explicit PRICE_BOX_BUDGET JSON file containing
`box` and `stop_before_utc`. The runner records it in RESULTS.json while retaining
the immutable shared source plan and all completed unit assignments. This does
not authorize rerunning an interrupted parent or changing the compiler pins.
