The refusal scan is generated by `refusalrewrite`, a Go AST transformation.
It retains production `lowering.refuse` and adds a measurement-only clone.
The syntax visitor and optional contract visitor each collect their own error
and continue their child walk exactly once. Module directives and checking
pragmas are collected separately. In full mode, diagnosed bodies are split into nested declaration units. All
existing no-output guards remain enabled.

The transformer requires `lowering.refuse`, its receiver/signature, the named
visitor/error pairs and exactly one child walk per visitor. Unsupported shapes
fail before writing the refusal overlay, with `lowering.refuse` and the missing
structure in the error. It never rewrites unrelated `return true` statements.
`go test ./stage3/census/latent/refusalrewrite/...` covers the complete 41231d51
source, compiled continuation/body-skip behavior, and missing-function and
changed-child-walk mutants. Top-level preflights are recognized by AST shape:
`if err := l.method(module); err != nil { return err }`, without a method-name list.
Wrapped errors, nested preflights, assignments instead of declarations and other
arguments fail closed. The slice-3 compiler snapshot and an unknown-name compiled
behavior probe hold this contract.

After all overlay rewrites, `importclean` parses every generated file and uses
`astutil.UsesImport` and `DeleteNamedImport` to remove unused imports. Explicit
blank and dot imports are preserved. This replaces the old textual removal of
`path/filepath`. Disabling production `Lower` also removes its async normalization
and error-location code, the only uses of `flow` and `errors`; those imports must
therefore be removed in the scratch copy. Production files are untouched.

This measurement binary sees beyond a program's first refusal. It is built with a
scratch Go overlay; no production compiler source is edited or committed. All
census numbers are **measured on a checker-rejected program**. It does not compile
or run native programs.

The overlay preserves the checker's diagnostics and admits its rejected program
only through `LatentLoad`. Ordinary `Load`, `LoadOverlay`, and `lower.Lower` are
disabled. The latter always returns nil IR and an explicit measurement error.
The ordinary driver fails unless replaced by the overlay. The measurement driver
imports no backend and checks the output guards when `LATENT_ASSERT_NO_OUTPUT=1`.

For each file, it scans refusal syntax without stopping at the first finding,
then attempts each top-level statement and each top-level function whose own body
has no checker diagnostic. It skips and counts diagnosed function bodies, using
raw diagnostic byte ranges rather than displayed line numbers. Signature-only
errors remain eligible. Each attempted unit gets fresh lowering state, with
project declarations registered and sibling signatures prepared lazily. A returned
error or recoverable panic becomes a finding; processing continues. Diagnosed
dependency bodies produce separate `SkippedDependency` events, excluded from
compiler NotYet/Refused counts.

Findings retain kind, location, exact reason/text, attempting unit, phase, and the
measurement label. Headline counts deduplicate `(kind, where, reason, text)` across
all attempts and attribute sites to their actual diagnostic file. Raw JSONL keeps
the attempt context, eligibility ledger, and raw checker spans.

Build and audit from a compiler checkout:

```sh
source /workspace/adamic-tools/env.sh
python3 stage3/census/latent/make_overlay.py "$PWD" /tmp/latent-overlay > /tmp/latent-overlay.log 2>&1
gofmt -w /tmp/latent-overlay/*.go
go build -buildvcs=false -overlay=/tmp/latent-overlay/overlay.json -o /tmp/latent-census ./stage3/census/latent/tool > /tmp/latent-build.log 2>&1
python3 stage3/census/latent/audit.py /tmp/latent-census > /tmp/latent-audit.log 2>&1
LATENT_ASSERT_NO_OUTPUT=1 /tmp/latent-census /path/to/adapted/src/compiler /tmp/latent.jsonl > /tmp/latent-run.log 2>&1
```

Set `LATENT_TIMES=/path/to/latent-times.jsonl` to record attempted units in a
separate JSONL stream. Each row has `file`, `where`, `wall_seconds` and
`cpu_seconds` (process user plus system CPU from `getrusage(RUSAGE_SELF)`).
First-error and full mode support timing. The sequential driver measures unit
registration, lowering and panic recovery; skipped and deferred units have no
row. This stream never changes the findings schema or adds nondeterminism to
`latent.jsonl`. The recorder in `timing/` is tested as an ordinary Go package and
compiled verbatim into the scratch lower overlay, including per-ref builds.

## Full latent measurement

Set `LATENT_FULL=1` when invoking the overlay binary. Unset retains the historical
first-error census for an exact same-input comparison. The twice-daily meter now
uses full mode by default; `STAGE3_METER_LATENT=first-error` selects the historical
mode. Neither mode changes production compiler sources or invokes a backend.

Every function declaration, including a declaration inside a diagnosed container,
is catalogued with its name, parent, top-level container, depth, and body byte span.
A body's direct checker diagnostics exclude diagnostics contained wholly inside
nested function declarations, including their signatures. Overlapping boundary
diagnostics remain conservatively owned. A directly diagnosed body is marked
`split_checker_body`; its nested declarations remain independently eligible.
The ledger names every excluded declaration and retains its diagnostics and span.
Diagnostic-bearing function expressions are still protected by the dependency
body guard; this expansion targets nested function declarations.

Each eligible declaration receives isolated lowering state and checked ancestor
bindings are registered lazily at their actual reads. Ancestor initializers never
run. Sibling signatures are registered without lowering diagnosed bodies. This
context permits observation of nested bodies; it does not prove closure support.

`statementrewrite` uses Go ASTs to wrap exactly `lowering.statement`, retaining
its original body. Missing methods or incompatible signatures fail loudly with
the method name. `statecopy` generates typed copies of lowering-owned state from
the compiler's actual declarations. Unsupported mutable state shapes fail before
publishing the overlay. AST/checker/program identities remain shared; owned maps,
slices, private structures, and IR state are copied. Before each statement attempt,
the overlay snapshots state. A failure or recoverable panic is recorded, the
snapshot restored, and the next statement attempted. This avoids letting a failed
declaration's partially installed local make a later read appear lowerable.

A failed construct may prevent examination of its children. Such a boundary is
recorded with its byte span and exact failure, rather than claiming its children
were measured. A signature or parameter prologue failure likewise records a
whole-body boundary and continues at the next independently catalogued declaration.
Snapshot failures and unit panics are explicit boundaries. The census therefore
remains an observation ledger, not an exhaustive list of expression-level blockers.
Final ownership, module ordering, and backend passes remain outside its scope.

`full_audit.py BINARY [EVIDENCE_DIRECTORY]` requires three distinct refusals from
actual lowering in one unit, named diagnosed nested exclusions, a clean nested
container with a diagnosed child, a clean sibling, and rollback of a failed
initializer. It runs `LATENT_MUTANT_FIRST_ERROR_ONLY=1` and
`LATENT_MUTANT_KEEP_FAILED_STATE=1`; both must fail those same assertions. The
existing legacy audits, refusal AST missing-function mutants, and no-output guard
mutants remain in use. Generated observation headers identify `latent_mode`.


Full evidence uses `stock_units.cjs ADAPTED SOURCE_MANIFEST OUTPUT_JSON` with
stock TypeScript 6.0.3 on NODE_PATH to enumerate declaration names, nesting and
UTF-8 body spans independently of the Go AST. `full_report.py ADAPTED RUN`
validates compiler/ and tsc/ observations against those ledgers and source hashes,
compares the same-input legacy checker diagnostics/spans, and writes complete
reason/owner, giant-body reason, named exclusion and recovery-boundary CSVs.
Its real-data mutants change a total, remove a nested declaration, change an
owner and change the baseline checker observation; all must fail their audits.
Reason CSVs flag both unowned rows and context-sensitive `reading X` observations.
Those reads can reflect incomplete isolated bindings after earlier failures;
they remain observed NotYet sites and require individual interpretation.


## Replay one lowering finding

From the repository root, run `go run ./stage3/census/latent/replay -project /path/to/adapted/src/tsc/tsc.ts -where /path/to/adapted/src/compiler/file.ts:LINE:COLUMN -kind NotYet -reason 'exact census reason'` (use the census source directory instead of the entry file for a directory census).

The command prepares the same guarded scratch overlay automatically. It loads the
same complete project, keeps all declarations and bindings, selects the smallest
eligible census unit containing the diagnostic node position, and attempts only
that unit through the full census code. Signature matching requires the exact
`where`, `kind` and `reason` fields from an actual `lowering` finding. Positions
are one-based lines and UTF-16 columns, as printed by the census. Use the same
source paths and bytes as the original run. Scan-only findings and findings whose
reproduction depends on a larger enclosing attempt can fail this assertion.

stdout is the selected unit's census JSON record, including its refusals in order.
stderr prints the matching refusal, load/register/lower time, and total time
including overlay generation and Go compilation. A missing signature exits
nonzero. Production Load and Lower remain disabled; the worker checks both guards
on every invocation. For repeated work, build the worker with the generated
`make_overlay.py` overlay and invoke it with the same arguments.

Run the two integration tests with
`python3 stage3/census/latent/replay/replay_test.py > /tmp/replay-tests.log 2>&1`.
They compare every finding, in order, against an unfiltered full census of a
nested body whose parent is checker-rejected, including an ancestor capture and
an imported binding. Selecting the parent's sibling must exit 1 at the signature
assertion. Run the positive test with `LATENT_REPLAY_MUTANT_PARENT_SIBLING=1` to
prove that the equality/reproduction check itself fails under that mutant.

[Replay validation and three real-project timings](replay/REPORT.md) compare the command with the 10,551-attempt full entry census.


## Speculative continuation

Set `LATENT_SPECULATIVE=1` on this same guarded overlay binary to recover failed
expressions, statements and signatures and visit their children. Normal builds
do not include the speculative implementation. `root_kind` is the exact reason;
`depth` counts failed AST ancestors, excluding the site's own boundary. The driver
buffers file observations until every file is examined so depth includes dependency
boundaries discovered later. It retains checker diagnostics and never emits IR.

[Speculative results](../speculative/README.md) contain the depth tables, top twenty,
coverage inventory, reproduction commands and mutants.
[Method and limits](../speculative/method.md) explain opaque checked placeholders
and how speculative examination differs from successful lowering.
`LATENT_MUTANT_NO_STUBS=1 LATENT_FULL=1` restores the existing full census exactly.

## Deferred generic coverage

Only generic function declarations, and declaration units nested under one,
receive `deferred_generic_instantiation`. Generic methods, arrow functions and
class type parameters do not trigger this deferral. Checker diagnostics remain
on deferred units and do not turn them into checker-body skips.

The overlay records `instantiated` for each deferred unit after all files have
been processed. It means a body entry was reached through a concrete generic
call with all binders mapped; it does not mean successful lowering or exhaustive
instantiation coverage. A nested unit needs its own body entry witness. Witnesses
survive recovery rollback and callers in later files. Never-reached units are
unexamined coverage gaps, never clean code. Deferred body bytes form their own
union bucket, neither examined nor blocked, even when a call witness exists;
that witness alone cannot prove byte coverage. The speculative traversal is
reported separately from concrete generic lowering coverage.

`audit_deferred.py BINARY OUTPUT` exercises unused, called, diagnosed and nested
generics and cross-file callers in legacy, full and speculative modes. It kills
missing-gap-list, deferred-as-attempted and deferred-bytes-as-examined mutants.
`prove_identity.py REPOSITORY OUTPUT BASE` compares overlay-off C and JavaScript
bytes against the given compiler base and proves both comparisons can fail.

## Checker relation overflow

The original program header is written and synced before lowering, so a cutoff
retains checker diagnostics. A final record with `status: "relation_report"`
contains `relation_overflow.after_load`, `relation_overflow.end` and the program
findings. Empty strings are explicit answers. The trailing record exists only
after the run completes; its absence means the end answer is unavailable.
By default only these two queries run. An overflow present after load marks every attempted unit. An
overflow first observed at the end conservatively marks every attempted unit
with phase `relation_overflow_conservative_all_units`; `attribution` explains
that the first affected unit is unknown. Both use Lower's exact NotYet words.
Skipped and deferred units are never treated as independent lowering attempts.

Per-unit probing proved costly on checker.ts: 51 calls took 32.599 seconds,
averaging 639.192 ms, versus 10.570 seconds of unit lowering. Across the stopped
cost experiment, queries consumed 972.056 seconds. This is why endpoint checks
are the default. `LATENT_RELATION_PER_UNIT=1` enables explicit measurement after
each attempted unit; only then do units include their `relation_overflow` answer.

`LATENT_RELATION_TIMES=/path/to/relation-times.jsonl` records query wall cost and
answer separately from deterministic census output. The two `where: "program"`
rows are the load and end observations, in that order. Opt-in unit rows use the
unit's exact location. `LATENT_TIMES` records lowering costs separately.

## Production prepasses

The census templates track production's pre-refusal passes in order. The in-process
AST guard follows Lower's local delegates and rejects missing
or reordered calls. Its adjacent exemption table explains why independent units do
not run the enum-validation and module-readiness preflights as unit first stops,
and why the element collector retains the conservative nil-key mode.
The two mutant test files prove omission and newly added production passes fail.

Fact collectors use the production ESM module order from the original input roots,
which the loader retains when an entry's observation ledger expands. Directory
measurements use the deduplicated union of those root orders. Omitted optional
facts join the registered program-facts capture; installations and snapshots own
separate maps. `LATENT_PREPASS_TIMES` optionally writes pass, attempting unit and
elapsed nanoseconds as tab-separated rows, outside the findings stream.

[Prepass evidence](evidence/prepasses/report.md) records scope, exemptions, costs,
paired observations and validation status.

Module-list preparation returns production ordering errors instead of using a
partial list. First-error units record and stop; full and speculative modes retain
file preparation failures and unit boundaries. `module_order_audit.py BINARY`
exercises a real production dynamic-import refusal on a tiny fixture, including
a selected file containing only generic deferrals. It uses an already built guarded
overlay and never builds one in a gate test.

## Deferred refusals

The `deferred` phase records the refusal registry's lowest-priority NotYet.
Production resets `refusal.deferred` for each module, visits its nodes in registry
order, and returns the first deferred stop only if no ordinary refusal wins
anywhere in that module. It does this before declaration and body lowering.
Today only `refuseAnyRelation` (ordinal 3270) defers: either a written-any member
relation or its structural-depth limit. `refuseInSlot` also selects this fallback
inside its value walk, then restores the enclosing deferred state.

Independent census units probe the production `refuseNode` walk on disposable
state before body lowering. An ordinary refusal anywhere in that unit suppresses
its deferred result; otherwise it records the deferred NotYet and stops the unit.
The continuing module scan reports its deferred fallback only when it collected
no ordinary finding, in phase `deferred_scan`. This separate scan phase prevents
a module at line 1 from impersonating its first unit at the same location.
Deferred findings retain their unit or module owner, and
pairing treats them as unit first stops. No lowering state field is added.

The real written-any regression runs in process with the census overlay:
`go test -tags=census_overlay -overlay=OVERLAY/overlay.json ./stage3/census/latent`.
The ordinary package guards the driver hooks. `deferred_read_mutant.py` copies
an overlay and replaces the shared fallback read with nil; the same census pin
must then fail because its eligible written-any function has no deferred stop.
Speculative mode records the stop and continues its deliberate recovery walk.
