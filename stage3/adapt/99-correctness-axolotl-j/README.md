## Why the two array sites are left

[array-witness.json](array-witness.json) is the unchanged witness output from `/workspace/scratch/99j-array-witness.json`. Its 99j-probe label refers to the rejected seventeen-site prototype, not the shipped fourteen-site adapter. The isolated witness transpiles the actual before and prototype handleOptionConfigDirTemplateSubstitution, startsWithConfigDirTemplate, getSubstitutedPathWithConfigDirTemplate and getSubstitutedStringArrayWithConfigDirTemplate functions; the harness supplies their external string/path operations and Debug.assert.

With an accessor-backed rootDirs string array, each indexed read returns a string. The rejected every check changes when those reads occur, so main substitutes the configDir value while the prototype returns the original options unchanged. This case uses native array methods. Separately, an own every method is never called on main but throws in the prototype. The ordinary-array control returns the same options on both. Array.isArray alone retains the existing wider union of array element types, so it does not establish string[]. No narrower valid-value domain is assumed to rescue an extra traversal. Neither left statement is an edit region in this adapter.

## Adapter contract

Stock TypeScript 6.0.3 parses each whole file. Nine unique enclosing function implementations are pinned by ownerBeforeSha256 and ownerAfterSha256 over their own normalized text, with named-function ancestry checked separately. No whole-file source hash gates the adapter. Each original statement is still matched by its exact AST statement text inside its owner. A changed, moved, missing or duplicate owner, changed statement, parse error, partly adapted owner/file/tree, or concurrent source change is refused before writes. Unrelated code outside these nine owners is allowed and preserved.

All edits are planned, all candidates are parsed and their after-owner hashes validated, and every original file is reread before any write. An already adapted tree returns zero files and edits without writes. CRLF is preserved. The fourteen transformations and javascriptChanging:true classification are unchanged; only validation scope changed. The three left casts remain outside edit regions, and other adapters can change unrelated functions without being rejected by a 99j whole-file pin.

It proves twenty refusals, including changed-owner and parse-error fixtures with no writes or byte/mtime changes, and accepts an unrelated function appended to sys.ts in both before and after states.
