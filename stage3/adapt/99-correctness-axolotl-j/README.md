## Why the two array sites are left

[array-witness.json](array-witness.json) is the unchanged witness output from `/workspace/scratch/99j-array-witness.json`. Its 99j-probe label refers to the rejected seventeen-site prototype, not the shipped fourteen-site adapter. The isolated witness transpiles the actual before and prototype handleOptionConfigDirTemplateSubstitution, startsWithConfigDirTemplate, getSubstitutedPathWithConfigDirTemplate and getSubstitutedStringArrayWithConfigDirTemplate functions; the harness supplies their external string/path operations and Debug.assert.

With an accessor-backed rootDirs string array, each indexed read returns a string. The rejected every check changes when those reads occur, so main substitutes the configDir value while the prototype returns the original options unchanged. This case uses native array methods. Separately, an own every method is never called on main but throws in the prototype. The ordinary-array control returns the same options on both. Array.isArray alone retains the existing wider union of array element types, so it does not establish string[]. No narrower valid-value domain is assumed to rescue an extra traversal. Neither left statement is an edit region in this adapter.

## Adapter contract

Stock TypeScript 6.0.3 parses all six files. The adapter locates each unique enclosing function implementation, pins its complete exact statement and the complete normalized before and after file hashes. Any changed surrounding code, moved owner, missing statement, parse error or partly adapted file/tree is refused before any write. The full-file pins also protect all three left statements and the reviewed control-flow guards.

Every edit is planned first. Every candidate is parsed and validated as fully adapted. All originals are reread before the first write. An already adapted tree returns zero files and zero edits, without writing. The composed source files' CRLF line endings are preserved. No line number locates an edit. The single commit contains adapt.cjs, README.md, the requested witness JSON, and the proof records. Only adapt.cjs defines the transformation.

## Note for stage3/upstream/LEDGER.md: a string parameter receives null

Do not infer the runtime domain from this helper's string parameter. In the valid javascriptProjectEmit test, outDir is explicitly null. toReusableCompilerOptionValue passes it through the erased cast into relativeToBuildInfoEnsuringAbsolutePath. TypeScript's declared type says string, but null reaches it. Adding an assertion changes this valid run; narrowing away null skips a call tsc makes.

Two-line Node run against the built main adapted tree, using the test's current directory, build-info directory and case-insensitive canonicalizer:

```js
const ts = require('/workspace/scratch/99j-lane-main/adapted-tree/built/local/typescript.js');
console.log(JSON.stringify(ts.ensurePathIsNonModuleName(ts.getRelativePathFromDirectory('/home/src/workspaces/solution/common', ts.getNormalizedAbsolutePath(null, '/home/src/workspaces/solution'), ts.createGetCanonicalFileName(false)))));
```
