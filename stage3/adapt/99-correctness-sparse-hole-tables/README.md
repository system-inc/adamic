## Premises and escapes

Each fill runs `while (table.length <= key) table.push(undefined)` before the existing assignment statement. On a cache hit the loop does zero iterations. On a miss, index readers see the same undefined as a hole. The existing assignment and its value evaluation remain intact. The flow readers use exact undefined checks, so cached false still counts as a hit. The generator's nested literal bucket still has its original identity. The outer label-expression array has no escape.

Checker IDs, generator labels, emitter IDs and completion-filter keys are existing nonnegative array indices.

The label-offset scans compare the element to a numeric operation index. Both an absent slot and a present undefined fail that comparison. The label-number scan checks the bucket against undefined before iterating. Both fills leave the post-write length as upstream would have left it. `markLabel` updates an index provisioned by `defineLabel`. Seven annotations account for materialized undefined slots. Reader-visible types and control flow otherwise stay as before. No public declarations are targeted. First-sample sizes feed pricing only. Each runtime write uses its actual key.

## Left out

The two indentation caches go together to Adamic. The owner cut `internedSpacesIndentation` because its callers have not established that its key is a nonnegative integer within the table’s real range of use. An Infinity key would never terminate an unguarded fill, and NaN accesses a named property. Both spaces and tabs retain their existing behavior.

The wave also excludes the 20 Performance entries and the separately handled token cache. The owner’s delete ruling for the outer System table applies in its eventual wave.

## Order and repeatability

Both receiver adapters sort before this adapter. Later adapters with a pin spanning a selected declaration or writer statement: none identified. The later generated-name adapter changes a separate autoGenerate read outside the writer statement. The full apply chain checks the ordering and all later pins.

Stock TypeScript AST selection uses owner paths and table/key members. Each declaration and writer statement must match the exact insertion-snapshot text. The rewriter plans and reparses all files before writing. It refuses a mixed adaptation and leaves bytes outside its edits intact. A second run changes nothing. The exported `rewrite(tree, {restore: true})` removes the exact fills and restores the type annotations.
