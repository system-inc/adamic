# getSupportedExtensions: widen the includes receiver

The includes test previously cast a string extension down to Extension solely to satisfy the receiver's element type. This adaptation instead views flatBuiltins as readonly string[] and passes x.extension unchanged. The readonly array upcast is accepted by Adamic. Both expressions compare the same receiver and argument with SameValueZero; the cast erases completely.

The complete top-level overload group and implementation are pinned before and after in owner.json, with SHA-256 digests. Stock TypeScript 6.0.3 locates the owner. Changed, missing, duplicate, nested and altered overload owners are refused before writes. The adapter preserves line endings, verifies full-file transpile equality with and without comments, and replays its own output with zero writes.

Run NODE_PATH=stage3/api/node_modules node stage3/adapt/99-correctness-supported-extensions/contract.cjs /absolute/path/to/adapt.cjs BASELINE_TREE for the drift and replay contract. Measurements and validation results belong on typescript/supported-extensions-evidence, outside stage3/adapt.
