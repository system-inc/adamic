# watchDirectory boundary normalization (#cyjqp5f)

The only new executable expression is System.watchDirectory's exact-parameter
forwarder at getNodeSystem. It passes path, callback and options unchanged and
normalizes recursive with !! before entering the unchanged boolean-only factory.
All 13 audited reads treat undefined as false; normalization does not introduce a
guard, default, host axiom or new signature anywhere downstream.

The whole-owner after text and SHA-256 amend the existing pin after #b8ffarm.
The before text, earlier 92/93 pins, imports and existing timer/require/resolve
amendments remain intact. The adapter validates the forwarder's four parameter
names/types/optional markers against the parsed System.watchDirectory member,
rejects rest/defaults, and checks its exact forwarding expression. Whole-owner
hashes reject drift, partial adaptation and duplicates before writing. Mixed
line endings refuse; LF and CRLF replay with zero writes.

Run the directory's prior require-result and resolve-host contracts plus
proofs/watch-directory-contract.cjs on a complete adapted tree. Its source-scope
oracle also undoes only this forwarder when checking the complete crypto chain.
proofs/watch-directory-witness.cjs evaluates the exact stock-emitted forwarder,
actual enclosing watch factory and actual Node fsWatchWorker with controlled OS
event delivery. Each of undefined/true/false is checked with native recursive
watch enabled and disabled; registration, callback and close traces must match.
No claim is made about comparing function identities or stacks.

watch-directory-mutant.cjs supports restore (original shorthand), unnormalized
(single-token normalization removal, retaining the boolean contract), and
optional-contract (unnormalized forwarding with propagated optional reader
contracts, reproducing the prior captured-optional-boolean failure). Each mode
is named explicitly in evidence; the single-token checker failure must not be
misrepresented as the optional-contract census failure.

under stage3/census/watch-directory-1533-forwarder/. They cover the full single-file
