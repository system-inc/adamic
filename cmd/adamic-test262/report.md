## Behavior and correctness

`-jobs` defaults to GOMAXPROCS. Workers compute independently; indexed reduction prints exactly the serial sequence, including progress totals and limit selection. `ADAMIC_GATE_UNCACHED=1` bypasses all three result caches. `-jobs 1 -compiler-subprocess` gives the original execution path; an explicit `-root` also retains that path to honor a different checkout.

Persistent compiler workers load with internal/load, lower directly, and emit C. Each worker is an isolated process with the existing compile deadline; a deadline kills and reaps it. The successful C result is additionally cached because lowering one large sort fixture still dominated the warm directory. Compiler errors/refusals remain fresh. Worker errors fall back to the original compiler command. Cached observations are interpreted by the unchanged verdict logic.

Under os.UserCacheDir()/adamic/test262, length-prefixed SHA256 keys and checksummed byte-preserving JSON envelopes are written by temp-file/rename. Node keys contain exact adapted program bytes, Node version, adaptation flags, and command. Native keys contain emitted C bytes, runtime library snapshot key, actual clang and run commands. Successful-C keys contain source bytes, compiler binary bytes, and actual invocation. All include runner/tool identities and execution context (environment, cwd, platform, uid, stack limit, deadlines and output limits). Stable per-program artifacts are protected by a cross-process file lock. Cache failures execute fresh; timeouts and failed starts are not stored. Programs with imports or reference directives bypass caches because their external input graph is not keyed.

The checked-in mini slice exercises pass, fail, refused, crashed and skipped. Its crash writes a sanitizer diagnostic to stderr to exercise the existing classifier. `TestParallelCachedMatchesSerial` compares serial subprocess uncached with parallel workers cached cold/warm, including byte-identical JSON/table/progress and limit behavior. Separate tests cover 50-test progress, changed bytes/version/flags/runtime key, corrupt evidence, byte preservation, bypass, worker deadline, unavailable caches, imported mutable files and reuse across default scratch directories.
