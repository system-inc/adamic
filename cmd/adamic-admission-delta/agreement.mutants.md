# Mutants for the agreement mode

The agreement mode runs every program head accepts, with no base, and judges each through the delta's own runner (judge.go). Each mutant is one edit, run on a Linux box against cmd/adamic-admission-delta, then put back and checked with `cmp`. Every row but one ran on Loom jobs J-sxha715 at 508b2dfe (main aee67a6c) and J-mndgp5y with this head's re-cut on main ae125455, each red at the test its row names, after the package whole was green and with the box's own ASAN_OPTIONS unset. The last four rows, and the held stop's stderr row as it now reads, are #d358hc1's: each ran on Loom job J-ghtdwn3 at 0aa36ed0, red at the test it names, after the package whole was green with TestHeldStopListHoldsItsRows over the list's 200 rows. The row collecting disagreements inside the worker is described, not run: its edit moves code across the pool, which a one-line substitution can't make.
