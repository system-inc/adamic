## Array creation, readers, and proposed adaptations

With an ordinary array prototype, a hole and a filled `undefined` slot yield the same indexed value and both produce `undefined` under `for...of`. A hole skips the callback in native `forEach` and `map`, and `map` preserves the absence in its result. `in`, `Object.keys`, and `for...in` can also distinguish a hole from an own `undefined` slot. A dense fill can preserve observed compiler behavior where the recorded array is private and consumers only index it. Where a consumer enumerates entries, a keyed collection must preserve presence or the producer must carry explicit presence information.

### Module initialization

- **`makeReverseMap`** starts with `const result: T[] = []` and writes `result[value] = name` in the source Map's `forEach` callback. The two module constants build reverse tables for tokens and regular-expression flags. The resulting arrays are private. `tokenToString` and `regularExpressionFlagToCharacterCode` each do a single indexed lookup, and a missing key yields `undefined`. Use a `Map<number, T>` built by setting the reverse key in the same producer order, then use `.get` in both readers. This preserves the last value if source keys share a reverse key. The traversal is over the input Map. The result has no length, array enumeration, or iteration consumer.
- **`createBracketsMap`** starts with `const brackets: string[][] = []`. Its four writes set `brackets[ListFormat.Braces] = ["{", "}"]`, `brackets[ListFormat.Parenthesis] = ["(", ")"]`, `brackets[ListFormat.AngleBrackets] = ["<", ">"]`, and `brackets[ListFormat.SquareBrackets] = ["[", "]"]`. The factory returns its array to a module constant. `getOpeningBracket` and `getClosingBracket` use the masked format as the first index and select slot 0 or 1 from the pair. Use a four-entry `Map<ListFormat, readonly [string, string]>` and keep the same masked lookup and pair index. The sparse outer array has no length or enumeration consumer.
- **`arrayToNumericMap`** allocates `result: (T | U)[] = []`, assigns `result[makeKey(value)] = makeValue(value)` while walking its input by index, and returns the result. Its only in-tree caller initializes `noRegexTable` in `src/services/classifier.ts`. The classifier tests `!noRegexTable[lastNonTriviaToken]` before rescanning a slash. Replace the classifier table with a `Set<SyntaxKind>` initialized from its existing token list and keep the test as `!noRegexTable.has(lastNonTriviaToken)`. The table has no length or enumeration consumer. This initializer belongs to the services module.

### Checker and flow analysis

- **`recordMergedSymbol`** stores the target in `mergedSymbols`, an empty array allocated per checker. `getMergedSymbol` looks up the merge ID and falls back to the original symbol if the slot is missing. Use a `Map<number, Symbol>`, preserving the same ID guard and fallback on `.get`.
- **`getSymbolLinks`** lazily stores a `new SymbolLinks()` in per-checker `symbolLinks = []`. A symbol ID indexes the memo table, and callers receive the cached object, whose identity and mutations matter. Use `Map<number, SymbolLinks>` with one allocation per missing ID and return the same object on hits.
- **`getNodeLinks`** similarly caches and hands out a `NodeLinks` object per node ID in `nodeLinks = []`. `getNodeCheckFlags` also uses the length as an upper-bound guard before reading the flags, defaulting to zero. Use a `Map<number, NodeLinks>`. A missing ID returns the same zero flags as either an in-range hole or a failed upper-bound check. Keep the negative-ID guard and object identity on hits.
- **`fillMissingTypeArguments`** starts with a slice of the supplied arguments or `[]`. It writes `errorType` in order to the missing tail before instantiating defaults. The second loop reads the full array through the type mapper and replaces those placeholders by index. The result is returned to signature/type instantiation and consumers that index, compare, iterate and read length. Append one `errorType` per missing parameter with `.push`, keep the second loop, and trim any excess JavaScript arguments only at the existing final truncation point. All appended slots were populated in the original.
- **`recursiveTypeRelatedTo`** lazily sets up `maybeKeys`, `sourceStack`, and `targetStack` as three empty arrays. `resetMaybeStack` walks `maybeKeys` by index up to the logical count to remove keys and cache results. The comparison helpers index the other two stacks up to their logical depths, and the trace calls native `.map(t => t.id)` over each entire backing array. Append only when the corresponding index equals the backing length, otherwise replace the existing entry. Preserve the high-water backing lengths and retained contents so the trace's `.map` sees the same entries after unwind.
- **`pushActiveMapper`** grows `activeTypeMappers` and `activeTypeMappersCaches`, both initially empty. The active lookup walks mapper indices in reverse beneath `activeTypeMappersCount`. Type instantiation selects a cache by index, and pop clears the mapper reference and clears the cache in place. Append a mapper at the backing end and overwrite on reuse. Add a fresh cache with `.push` on first use at a given depth and keep the cleared Map at that depth for reuse. The arrays are private and logically bounded by the depth counter.
- **`getEvolvingArrayType`**, **`isReachableFlowNodeWorker`**, **`isPostSuperFlowNode`**, and the flow-ID cache in **`getTypeAtFlowLoopLabel`** each start from a per-checker `[]`. They index by element type ID or flow-node ID. The evolving-array lookup returns the cached Type object. The two boolean lookups distinguish a cached `false` from an absent slot. The loop lookup creates and then uses an inner `Map<string, Type>`. For each, use a number-keyed Map with the same miss check and store; preserve `false` and keep the same cached Type or inner Map on hits.
- **`getTypeAtFlowNode`** stores paired node/type entries in `sharedFlowNodes` and `sharedFlowTypes`, both initially empty. It scans a bounded range of indices for the node and reads the corresponding type. **`getTypeAtFlowLoopLabel`** likewise saves a node, key and antecedent array in the initially empty `flowLoopNodes`, `flowLoopKeys` and `flowLoopTypes`, and looks them up over its active counter range. It reads the matching inner array's length before forming a union. Append a new slot at the backing end and reuse existing slots after unwind. Keep the counters and continue passing the same inner antecedent list.
- **`pushContextualType`** and **`pushInferenceContext`** store frames in initially empty per-checker parallel arrays. The contextual lookup scans node and cache-flag entries backward, then returns the type by index. The inference lookup scans for an enclosing node and returns its context by the same index. The pop routines clear references at the previous depth. Append at the backing length and assign on reuse, preserving the same indexed lookup and reference clearing.
- **`setLastResult`** uses the binary-expression work state's `typeStack`, seeded as `[undefined, undefined]`. Binary traversal reads the left operand from the current slot and the last result from the next slot. Append when that next slot equals the backing length and otherwise replace it. The stack itself stays in the work state.
- **`getTypeOfExpression`** initializes `flowTypeCache` to `[]` on demand and stores the expression's computed Type by node ID. Its guarded reuse is by ID; flow paths can temporarily swap out and later restore the whole cache. Use a `Map<number, Type>`, with the same flag, miss check, and save/restore boundaries.

### Binding, emitter, and transformation state

- **Binder `onEnter`** stores strict-mode and parent state in two one-element arrays seeded with `undefined`. The exit callback retrieves the same index to restore each value. At the backing end, append the saved value to each stack. Retain in-place replacement for reused frame indices.
- **Emitter `onEnter`** stores six pieces of frame state in parallel one-element arrays, seeded with `undefined`, three instances of `-1`, and two instances of `false`. The exit callback uses the current frame index to restore the newline and source bounds and check the two emit decisions. Append when the frame is the next backing index, otherwise overwrite; evaluate each comment/source-map decision once and keep its local value for the rest of the callback.
- **Emitter `generateName` and `generateNameCached`** use three arrays reset to `[]` for each emitter reset. Generated-name IDs key the first site, and node IDs key the public/private name caches at the second. Consumers get individual cached strings for emission. Use three `Map<number, string>` caches with the same resets, lazy generation, and lookup order.
- **Binary-expression `pushStack`** appends a new state-machine handler, node, and user-state slot to stacks seeded with their root frame. Other states read by index, including the prior user state. A debug circularity check walks active node indices. Use `.push` at a new deepest frame and keep indexed replacement on reuse, including the explicit `undefined` reset of the user slot. The arrays are internal to the trampoline.
- **`startLexicalEnvironment` and `startBlockScope`** save declarations, statements or flags in per-transform stacks initialized to `[]`. Their end routines restore the saved values by depth and reset the backing arrays when the outermost scope ends. Append all the corresponding values at a new deepest index, preserving existing-slot overwrite and the reset. The groups of declarations can be handed back by the end routines. The backing stack arrays stay private.
- **Module `transformSourceFile`** initializes `moduleInfoMap` to `[]` in the transform factory. Emit retrieves the per-file metadata by original node ID. Use a `Map<number, ExternalModuleInfo>` and keep the lifetime of the per-file records and access by ID.
- **Module substitution setters `visitPreOrPostfixUnaryExpression`, `substituteCallExpression`, `substituteTaggedTemplateExpression`, and `substituteBinaryExpression`** write only `true` into the transform's initially empty `noSubstitution` table. The substitution test checks the truthiness of the node's indexed value. Use a `Set<number>`, adding on the same paths and using membership in the substitution check.
- **`multiMapSparseArrayAdd`** receives `exportedBindings`, allocated as an empty array in `collectExternalModuleInfo`. It looks up a declaration ID, creates a one-element list when absent and appends to it on later hits. The outer table is handed out as part of module metadata. The CommonJS and System transforms read particular keys, and then use individual binding lists in their existing order. Use a `Map<number, ModuleExportName[]>` for the outer table, retaining each dense inner list and returning `undefined` for absent IDs.
- **`setSourceContent`** lazily starts `sourcesContent` at `[]` and already pushes `null` for positions before the index. It writes the content by index, and `toJSON` hands out the array as the source-map content vector. JSON serialization sees the array's length and positions. Once the existing null-padding loop finishes, append the string if the index equals the current length, otherwise replace the previous content. Keep the lazy initialization and null positions.
- **`setTokenSourceMapRange` and `mergeTokenSourceMapRanges`** start from an empty per-emit-node array or reuse the destination's existing one. The metadata is stored on `EmitNode` and handed through clone/merge. `getTokenSourceMapRange` and the printer look up a token kind by index. The merge uses `for...in` over the source, so a hole preserves an existing destination value while an own `undefined` can overwrite it. Use a numeric record with only explicit entries, preserving numeric key enumeration and permitting an explicitly stored `undefined`. Copy present keys only and retain the existing last-writer behavior.
- **ES2017 `transformMethodBody` and `transformAsyncFunctionBody` and ES2018 `transformAsyncGeneratorFunctionBody`** store `true` in an initially empty `substitutedSuperAccessors` table in their respective transform factories. The emit hook checks the node ID's truthiness to select the super-access substitution. Use a `Set<number>` in each transform, with `.add` on each writer and `.has` in the hook.
- **System `transformSourceFile`** writes `moduleInfoMap`, `exportFunctionsMap`, `contextObjectMap`, and `noSubstitutionMap`, each initialized to `[]` per transform. During emit, the original source-file ID retrieves the module information, identifiers and set of excluded nodes. The emit hook deletes the saved exclusion set after retrieving it. Use keyed Maps for the four tables and keep the original delete/restore lifetime. **System `preventSubstitution`** lazily starts the inner `noSubstitution` array at `[]`, sets a node ID to `true` and uses indexed truthiness in the substitution check. Use a Set for that inner table, including when it is stored in the per-file Map.
- **Generator `defineLabel`** lazily starts `labelOffsets` at `[]`, assigns `-1` to the next label ID and later replaces that slot in `markLabel` with the operation offset. Emission walks numeric indices up to `length`, comparing to a concrete operation offset. Seed the unused label-zero slot with explicit `undefined` and append one `-1` per newly defined label. The scan sees the same non-match for label zero.
- **Generator `beginBlock` and `endBlock`** share three lazily initialized empty arrays. Both append a block action, the current operation length (or 0), and the block object at the index taken from `blockActions.length`. The emitter scans the actions by length and uses matching offset and block indices. Push each value to its corresponding array in the original order.
- **Generator `beginCatchBlock`** lazily initializes `renamedCatchVariableDeclarations` to `[]`. Its consumer looks up a renamed identifier by original declaration ID while visiting expressions. Use a `Map<number, Identifier>` with the same lazy setup and fallback.
- **Generator `createLabel`** lazily creates `labelExpressions = []` and starts a dense list of numeric-literal nodes at the requested label ID. Later references append to the same list. Two emit routines index by label and either test presence or iterate the inner list to patch each literal. Use a `Map<number, Mutable<LiteralExpression>[]>` for the outer table and preserve the inner order and identity.
- **Generator `emitWorker`** initializes three empty operation arrays on first use, then stores the opcode, optional arguments, and optional source-map location at `operations.length`. Later emit uses the operation list length and indexes all three arrays in lockstep. Push the values in that order, including explicit `undefined` for missing arguments or locations.
- **Generator `tryEnterLabel`** lazily creates `labelNumbers = []` and writes the first label list at its generated case number. Later matching labels push into that list. `updateLabelExpressions` scans case numbers from zero to `length`, skipping undefined buckets and iterating only the inner lists. Extend with explicit `undefined` up to the case number and push the new list, or replace an existing empty slot. This preserves the scan length and order.
- **Class fields `visitClassDeclarationInNewClassLexicalEnvironment` and `visitClassExpressionInNewClassLexicalEnvironment`** store aliases in a lazily allocated `classAliases = []`. During identifier substitution the transformer reads the referenced declaration ID and clones the stored alias when present. Use a `Map<number, Identifier>` with the same store, lookup, and cloning points.
- **`addDefaultValueAssignmentsIfNeeded`** creates a copy with `parameters.slice(0, i)` at the first changed parameter, then assigns all subsequent parameters in order. It hands the dense array to `createNodeArray`, and visitors and emit consume the parameter list by index, length, and traversal. Push `updated` onto the copied prefix for every remaining parameter and retain the original fast path that returns `parameters` when nothing changed.
- **Legacy decorator `getClassAliasIfNeeded`** uses a separate lazy `classAliases = []` for decorated class declarations. It stores the generated identifier under the original node ID, hoists it and returns it. `trySubstituteClassAlias` retrieves it by declaration ID and clones it when present. Use a separate `Map<number, Identifier>` and retain hoisting, return identity and the clone.
- **Source-map `getSourceMappings`** groups decoded mappings into a fresh `lists: SourceMappedPosition[][] = []`, creating one list for an encountered source index. It traverses decoded mappings in order, then native `lists.map` sorts and deduplicates each present list. Native `map` skips holes here. The resulting cache is queried only by source index, with absent lists used as misses. Use a `Map<number, SourceMappedPosition[]>` to collect lists and build the cache by sorting and deduplicating present keys.
