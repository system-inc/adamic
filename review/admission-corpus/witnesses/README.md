# Admission-delta witnesses

Small programs the test audit (Oct 9, #xphstyt) found that separate a miscompile from a correct build. cmd/adamic-admission-delta reads them as the `witnesses` corpus (cloud/admission-corpus/manifest.py), first, so a deterministic sample never drops them. Each runs on Node, through the JavaScript backend and natively, and the three must agree byte for byte.

- checked-view-boolean.a: a downcast through a readonly view of a union holder (unit u058, internal/oracle checked_views_v2_source).
- captured-loop.a: a closure over an array read inside a for-of loop (unit u048, internal/native library).

The empty-else switch witness lives at review/compiler/empty-else-guard/survivor-switch.a (the compiler's, #qa0ybgb) and is drawn by the `review` corpus.
