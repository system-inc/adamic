These do not lower. Node runs the same source. Native does not produce the Node stdout.

A parameter-property default that reads this.x before the store:

source:
class C { constructor(readonly x: number, readonly y: number = this.x) {} }
const c = new C(1);
console.log(`${c.x} ${c.y}`);

Node exit 0, stdout:
1 undefined

native:
Adamic 0.1 refuses this in a field initializer before the fields it reads are initialized; declare the field it reads earlier, or initialize it in the constructor after super and all required fields are set

A reopened namespace:

source:
namespace N {export const x=1;} namespace N {export const y=2;} console.log(`${N.x} ${N.y}`);

Node exit 0, stdout:
1 2

native:
stage 0 can't lower a reopened namespace or namespace merged with a runtime value; put the declarations in one namespace or use a module

var inside a namespace:

source:
namespace N {var x=1; export function read():number{return x;}} console.log(`${N.read()}`);

Node exit 0, stdout:
1

native:
stage 0 can't lower var inside a namespace; use initialized private let or const

A namespace function that uses this:

source:
namespace N {export function read(this:{readonly x:number}):number{return this.x;}} console.log(`${N.read()} ${N.read.call({x:4})}`);

Node exit 0, stdout:
undefined 4

native:
Adamic 0.1 refuses this in a namespace function; a qualified call and a detached call have different receivers; pass the state as an explicit parameter instead of using this

An executable namespace body. A call is refused while the namespace is still uninitialized:

source:
namespace N {console.log('effect');} console.log('after');

Node exit 0, stdout:
effect
after

native:
stage 0 can't lower a call before all runtime namespaces are initialized; put namespaces before executable module code

A body statement that is not a call:

source:
namespace N {1;} console.log('after');

Node exit 0, stdout:
after

native:
stage 0 can't lower a namespace member other than a function, type, initialized binding or nested namespace
