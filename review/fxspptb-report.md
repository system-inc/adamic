## Method and evidence

All 173 programs ran through source Node using `oracle/node.mjs`, `adamic build --sanitize`, default `adamic build` (-O2), and `adamic js` followed by Node using the same oracle runtime. Each subprocess used a separate process group and a 30-second wall-clock deadline; the group was killed on timeout. Four fixture workers ran concurrently. The package test gate overlapped the first pass, so timeout measurements are under that load rather than isolated performance claims. No oracle result cache was used for the scratch executions.

Sanitized builds use native.Flags: C11, -Wall -Wextra -Werror -Wcast-function-type-strict -pedantic, the existing unused/self-assignment suppressions, -ffp-contract=off, -fno-optimize-sibling-calls, -O1 -g -fsanitize=address,undefined -fno-sanitize-recover=all. The comparison runs set ASAN_OPTIONS=detect_leaks=0 and UBSAN_OPTIONS=halt_on_error=1. Every candidate agree fixture also ran with ASAN_OPTIONS=detect_leaks=1 and had to match Node with exit 0 and no sanitizer output.

Only diagnostics produced by lower.NotYet ("stage 0 can't lower") or lower.Refused ("Adamic 0.1 refuses") in all three compiler invocations qualify as refused. Generic loader/checker/clang errors and Go compiler panics do not. All-four agreement with exit 70 is retained: it does not finish cleanly under step 2. Two cycle probes match four ways but fail the additional leak check and are retained.

[Full observations](fxspptb-observations.json) include all 173 classifications, commands, exit codes, timeouts, elapsed seconds, diagnostics, source hashes, destinations, and Base64 stdout/stderr bytes for every execution plus compiler stderr. Generated compiler stdout is recorded by byte count and SHA-256; the generated artifacts remain in scratch storage. The table abbreviates long outputs; the JSON is the complete byte-exact evidence. Negative exit codes in the JSON denote signals.

The initial six Node host compilations reported missing @types/node 25.3.3. `npm ci --ignore-scripts --prefix stage3/api` installed the pinned lockfile dependencies successfully, and all six were rerun in every mode. Final evidence supersedes those missing-dependency observations. The two remaining host discrepancies are error formatting, not missing setup.

No discrepancy was identified as solely path, timing, or PID nondeterminism. Sanitizer report addresses/PIDs vary, but their reports and abnormal exits are material failures. The programs that create temporary directories and compare or normalize their paths passed when their observable bytes matched.
