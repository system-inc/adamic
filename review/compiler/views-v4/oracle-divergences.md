# V4 direct-call oracle divergences

Argument/result contract violations intentionally stop with exit 70 at invocation. Node running the original misfit source evaluates the argument, then executes the producer and prints its result. The checked native and JavaScript backends preserve argument output, then stop before an invalid producer argument or after an invalid returned result. Diagnostics name view.run, the call site, and producer/view types. Scalar, object, and array argument probes and the result probe pin this difference.

A noncallable member evaluates its argument before Node throws TypeError. Both checked backends preserve that output, then report exit 70 with the callable and call site. TestV4DirectCalleeOrder pins this difference.

Compatible calls, methods, boxed representations, optional receivers, null, void, unknown producer parameters, class results, and unused misfit callables match Node. Recursive-domain refusal probes execute successfully in Node; Adamic refuses the unproven relation with path and fix.

Escaping .ts callable adapters defer signature checks to invocation. Source Node runs the misfit function unchecked; both generated backends instead exit 70 after argument effects for an argument misfit, or after producer effects/return for a result misfit. TestV4EscapeAdapterArgument and TestV4EscapeAdapterResult pin stdout and identical generated-backend diagnostics, and omission mutants must finish leak-clean with source Node's output. Unused signature misfits do not fail at read. Adapter blame now names the original read site and actual later source call site for direct calls, call/apply and bound calls. Runtime callback IR lacks a source call position; TestV4EscapeAdapterBlameRuntimeCallback remains pending, and its diagnostics explicitly say <runtime callback> rather than inventing a position.

Escaped adapter call/apply surface invocations preserve callable, receiver and argument evaluation order, then intentionally exit 70 for producer argument or viewed result violations. Source Node executes the same misfit unchecked. TestV4EscapeAdapterCallArgument/Result and ApplyArgument/Result pin this divergence in both generated backends. Receiver-domain violations similarly fail after argument effects; the receiver omission mutant reaches source Node's output. Compatible object receivers, actual argument counts, sort and RegExp callback controls match Node. Dense literal apply is admitted; unsupported argument-list/receiver representations remain refused.

Checked bind validates only the supplied argument prefix, after callable, receiver and all captured-argument effects, without invoking the producer. TestV4EscapeAdapterBindPrefix intentionally exits 70 at bind while source Node constructs the unchecked bound function and prints its next line. Later bound calls preserve argument effects before producer-domain checks and producer effects before viewed-result checks; TestV4EscapeAdapterBindRemainingArgument and BindResult pin those divergences. Each omission mutant completes with source Node's output in native, sanitized native and JavaScript. Compatible calls, receiver/value snapshots, actual argument counts, boxed arguments, fully captured arguments and bound length/name match Node. Bound call/apply and repeated bind remain compile-time refusals with path and fix. Re-viewing a bound wrapper remains refused rather than inventing the captured producer's signature.

Far-escaping values passed through a function retain the read site at invocation. TestV4EscapeAdapterBlameArgument/Result/Call/Apply/Bound compare identical native and JavaScript exit-70 diagnostics to the checked expectation while retaining unchecked Node output as the intentional divergence. Their read-site omission mutants still exit 70 with the same output and actual call site, but lose the required original read site. A nested compatible adapter invocation restores the outer call context before its result check. No additional runtime heap allocation occurs on successful calls.

Generic relations use a reached direct call's checker-resolved instantiation when the resolution belongs to the declared signature. A generic producer instantiated by the existing monomorphizer records the concrete parameter/result domains rather than their binder names. TestV4GenericProducerInstantiation and TestV4GenericViewCallInstantiation pin argument/result exit-70 divergences from unchecked Node; omission mutants finish with Node output and no leaks. An escaping quantified relation with no runtime witness remains refused in .ts with path and fix. The trust-erased compiler mutant cleanly admits and runs that read in both backends and sanitized native, then fails its refusal assertion. First-class named generic producer dispatch remains unsupported by the existing generic-function-as-value boundary.
