## Brief issues, mistakes and costs

1. The brief says nine rows but supplies 10266 functions. All requested names exist and none vanished. The generated files were validated in full as 8192 and 2048 uniform wrapper bodies. Grouping identical-input checker wrappers, while separating agreement/benchmark assertions and the two different upstream checker implementations, produces 11 rows. Full membership is supplied, not inferred from file names. Port union belongs with agreement corpus coverage; upstream union belongs with its top corpus family. Preparation-only aliases form their own family because they do not execute the parity check.
2. The whole package has 10422 top-level Test names and exceeded 90s. A complete package matrix and full three-run large-family medians were not feasible in the budget. A conservative static port function closure is recorded; dynamic coverage of every conditional helper was not produced. This limits reach and uniqueness claims. The 17 selected boundary buckets cover generated empty containers, nested objects, Unicode, numbers, comments, malformed numbers, incomplete input and empty input; the paired benchmark selectors select round zero only.
3. Saving matrix-rows.json contaminated the live repository corpus. The initial bounded run failed with unexpected untracked JSON; I renamed it to matrix-rows.txt and reran the clean baseline green before any mutant. That failed setup run is preserved as bounded-baseline.log.gz and supports no verdict. Evidence files all use .txt or .gz, so they cannot add JSON corpus inputs after commit.
4. /usr/bin/time was absent, so the first npm command did not execute. A corrected npm ci succeeded using bash time. I initially installed the wrong Prettier version, noticed the library's pinned 3.9.6 check before baseline, and replaced it. These were setup mistakes, not red production baselines.
5. The first W2 standalone attempt incorrectly removed fmt even though the witness still uses it. go vet rejected that attempt; no test result or kill is counted from it. The corrected standalone W2 diff retains fmt and passed vet and its weakened-check run. The runner traceback is retained. Replay W2/W3 and construction via follow.py after audit.py; the saved scripts document the actual session, including the rejected compilation attempt, rather than silently rewriting it.
6. The production menu was frozen before mutation. S4/S5 were added to the construction menu after port results, before their construction runs; this departs from a single immutable whole-unit menu. They use permitted off-by-one/constant operations, and only construction verdicts depend on them. Central replay should retain this limitation. Harness experiments were compiled sequentially rather than with one switch; port rebuilds were limited to three production variants and one probe.
7. Sources are TypeScript ports, not Go formatter implementations. Go cohere is an oracle here. Mutating its matcher or printer would settle the wrong question. There is no applicable port entry for the upstream-only comparisons, and no permissible empty-answer oracle probe; vacuity remains null there.
