Object.fromEntries does not run natively. Stage 0 refuses it before a binary exists, so it is not an oracle fixture.

source:
const fields = { c: 1, '2': 2, b: 3, '10': 4 };
const made = Object.fromEntries(Object.entries(fields));
console.log(Object.keys(made).join('|'));
console.log(`${made.c} ${made.b}`);

Node exit 0, stdout:
2|10|c|b
1 3

native:
adamic: /tmp/object-from-entries.a:2:14: Adamic 0.1 refuses Object.fromEntries; tsc returns an index-signature object with unproven keys; Adamic fixes object shapes and refuses index signatures; use Map
