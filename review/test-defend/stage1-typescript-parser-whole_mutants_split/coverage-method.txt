NODE_V8_COVERAGE was separately set to /tmp/defend158/v8-compiler and /tmp/defend158/v8-yield. V8 ranges measure the source executed by Node, after oracle/node.mjs strips TypeScript using node:module stripTypeScriptTypes(mode: transform). Native code is not instrumented.
The same stripTypeScriptTypes call with sourceMap:true produces the saved transformed.js.txt files and inline source maps. Decode base64 VLQ mappings into generated offsets and original TypeScript lines. For each mapped point choose the enclosing V8 range with the smallest span; count > 0 means covered. A line is recorded if any of its mapped points is covered. coverage-diff.json records both rows and their difference; exclusive-lines.json includes original source text. These are mapped-point leads, not proof that every branch or every character on a line executed. exclusive-functions.json separately records positive function-call counts versus zero calls in Yield, with generated coordinates explicitly labeled.
