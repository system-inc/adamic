Failures of tests named Mutant, Mutants, Planted or Disagreement, including their product/setup rows, are conservatively excluded as surviving production catchers. Bodies additionally inspected: TestAcceptanceDiagnosticControl disables syntax validation; TestLossyInputControl runs a lossy-input mutant; TestPortStallControl wrappers run a stalled-port control. These are excluded too. TestRecoveredExpressions compares normal source/native/emitted outputs against Go, and TestUnattachedDecorator checks the normal port refusal; these remain ordinary catchers. Every excluded observed failure is stored in witness_failures. Go panic stacks are drained before any clean catch is accepted; panicking tests are added to the next skip expression and receive no credit as catchers.
