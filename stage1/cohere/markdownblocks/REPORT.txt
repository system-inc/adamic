The requested all-file default-mode simultaneous target has conflicts

The Go auto baseline invokes cohere/internal/format/native.Formatter, which reaches
its real Markdown parser, printer and native embedded-language dispatch. This is
the upstream Go native-printer target; it is not the command/cohere formatter's
JavaScript-engine output. The fork baseline invokes the exact committed standalone
and seven plugin bundles directly on Node. Both use the same explicit options:
tab width 4, print width 120, spaces, semicolons, single quotes, preserved prose
and the remaining Prettier defaults. Per-repository configurations and ignore
rules are not applied to this census.

Go native/json.go registers .json, while an embedded jsonc maps to embedded.jsonc.
The Go Markdown formatter consequently preserves those fenced contents. The fork
formats them. In the existing TypeScript VS Code README this is a trailing-comma
difference. gaps/embedded_jsonc.md reduces it to a single field: Go keeps the field
without a comma and the fork inserts one. Its outputs differ at byte 21.

Six existing Flow fixtures also differ through the Babel/native JavaScript path.
gaps/embedded_flow.md reduces a formatting difference to an @flow generic function;
Go preserves its tight parameter/body spelling, while the fork formats it. Its
outputs differ at byte 39. The state of native JSONC/Flow embedded formatting is
outside this new stage-1 folder's territory. An Adamic output preserving these Go
native defaults cannot simultaneously equal the different fork default outputs.

The initial baseline was 873 physical files plus 75 generated inputs: fork auto
941/948 identical (7 existing file differences), stock npm auto 788/948 identical.
Both JavaScript off baselines agreed with Go on all 948. The final branch adds its
GAPS.md and two Markdown witnesses, and checks each witness again as a generated
case: 876 physical files plus 77 generated cases, 953 total. Fork auto is 942/953
identical, with 11 named discrepancies: the original 7 plus the 4 witness instances.
All 953 match in off mode. Stock npm auto is 789/953 identical (164 differences),
and stock off is 953/953 identical. There were no top-level formatting errors.

This is an observation about these selected entry points/options, not a claim that
Markdown cannot be implemented in Adamic or that all possible Go Markdown embedding
callbacks disagree. The existing upstream corpus test can supply the JavaScript
oracle for embedding to isolate the Markdown core. An explicit embedding-off
contract would likewise avoid the demonstrated JSONC/Flow target conflict. The
scope question was presented during work; no answer was received before this report.
I retained both measurements rather than silently claiming the default target passed.

The parser also needs a representation change before a literal port lowers

Micromark represents a state as func(code Code) State, nil at completion, with
captured mutable frames and mutually referring state closures. The minimal probes
separate three facts:

1. gaps/1_recursive_state.ts: Node prints 35 twice. load succeeds; lower returns
   NotYet with exactly "a function inside a function (a closure)".
2. gaps/2_state_arrow_cycle.ts: Node prints 35 twice. A mutable arrow-state cell
   that its closure captures is Refused by Adamic 0.1 as a reference-counting cycle.
   This is a language refusal, not a compiler feature promised to arrive later.
3. gaps/3_recursive_callable.ts: noncapturing top-level recursive callable state is
   supported. Source Node, the JavaScript backend, native ASan/UBSan and native
   LeakSanitizer all agree on 1 then 0, with zero exit and no stderr/leaks.

The recursive callable type itself is not a blocker. Explicit state/frame IDs,
owned arenas and appropriate weak back references are a possible porting approach;
that complete engine transformation was not done. I did not replace the micromark
parser with an approximate line scanner, hand original parsing off to Node/Go in an
alleged native formatter, or edit compiler-owned files to hide the representation gaps.
