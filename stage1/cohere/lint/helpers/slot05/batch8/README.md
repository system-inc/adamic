# Slot 05 eighth batch

One helper per .a file. types.a holds the common data and dependency interfaces.

parseCandidate(input, dependencies, arena) returns all readings in Go order. It preserves prefix checks, reverse variant consumption, importance spelling precedence, static-first yields, modifier truthiness, arbitrary properties, shorthand rewriting, explicit type hints, named fractions and early return versus continue. Existing segment, decoder, validity, modifier and root-search helpers are callback dependencies rather than copied implementations. It uses this batch's actual parseVariant.

parseVariant(input, dependencies, arena) returns an index, with -1 for Go nil. Each successful compound points to a previously appended child, so the variant graph has no recursive ownership links. It preserves selector wrapping and relative flags, static/functional guards, root precedence, shorthand values, compound compatibility and not/has/in modifier forwarding. The arena belongs to the caller and must outlive every returned candidate; use a fresh arena per independent query or retain its existing indexes unchanged. Failed queries may leave unreachable appended child records; callers only read reachable indexes. Nil modifiers and values use explicit presence bits.

loadDesignSystem(options, dependencies) returns an explicit success bit and an error string. It refuses missing configuration before calling dependencies, resolves an absolute entry, creates one fresh collector, loads it once, and short-circuits graph failures without returning partial state. Nil framework overrides are distinct from explicitly empty overrides. Registration order is framework, theme breakpoints/comparisons, then sorted repository variants; an evaluator is created only when definitions exist, and a successful build increments the externally owned counter once. Collector/theme/registry/evaluator values are opaque engine handles. Their provider must retain them for the returned system's lifetime; this helper neither parses their payload nor performs unrecorded IO. Filesystem, collector, registry, normalizer and counter implementations remain with their existing owners. This unit delivers orchestration, not those components or a runnable complete linter.

The private oracle overlays instrument the actual Go functions at pin 715ba94f3608a6500086b1076ce5cb7e51b836db. Wrappers call the original dependencies and record their answers and operation order. The cohere worktree is untouched. The parser corpus includes all six consumers' nonempty test-file literals and whitespace fields, the 5,056 pinned candidate fixture inputs and explicit branch controls. Candidate inputs are checked under empty and tw prefixes. Variant coverage additionally uses actual bracket-aware variant segments and controls for every generated framework root. A real loaded Go design system supplies registration/compatibility answers. Fixture inputs are reused, but the expected result is actual Go in that system, not the JSON fixture's separately captured expected engine result.

Loader cases read real temporary stylesheets built from all 639 consumer literals placed in comments. They vary empty/custom/nil framework overrides, absent/present evaluator definitions and malformed CSS, with additional configuration, resolver-selection and missing-file controls. The adapter receives the actual Go collector result; full CSS parsing, import resolution and variant registry algorithms are explicit separately owned dependencies. Trace and result fields must agree with Go, including nil-versus-empty override behavior and counter values.

Baselines compare actual Go, source Node, emitted JavaScript and native under ASan/UBSan. Every credited mutant compiles, exits zero without stderr and differs semantically from Go. Missing oracle answers, crashes and compiler failures are never credited as kills. See REPORT.md for the superseded failures and final witnesses.
