# Utility description projections and font-stretch percentage

functionalDescription converts the relevant FrameworkFunctionalUtility fields into a fresh UtilityDescription. It preserves the theme array's identity and order, negative/default fields, and exact bare-handler construction arguments. Fractions and the other unset fields stay false. Static names form a fresh deduplicated true-valued map only when present; empty input means Go nil, represented by staticNamesPresent false. Property names, emitted CSS and static values are outside this conversion: only their names are read.

multiDescription projects the same fields and also supports fractions. Its static map and negative handler, arbitrary-modifier and arms fields are absent, as in Go. Refusal flags, color keywords, literal readings and measured emission counts belong to other helpers and are not consumed by Description.

model.a contains only the owned data types. Go nil arrays/maps/functions use explicit presence flags. Empty-but-present theme arrays remain distinguishable from absent arrays. An absent map or function's placeholder must not be observed or invoked. Bare-handler construction is an explicit callback dependency returning a presence flag and call function on ParsedValue; these two helpers do not implement the handler body. Their returned theme array deliberately aliases the input, while present static maps are new on each conversion.

isFontStretchPercentage first requires a trailing percent sign, then invokes the supplied Go-compatible float parser on the remaining spelling. It rejects parser errors, non-integral values, values below 50 and values above 200. Both endpoints are included; decimal, sign, exponent, underscore and hexadecimal float spellings follow strconv.ParseFloat through the parser dependency. The dependency result includes its error status, and callers must supply matching Go parse semantics. No numeric parser or regex matcher is implemented here.

Tests wrap unchanged original Go helpers, capture every consumer test-file string, project helper inputs, and include all 185 real framework rows. Actual Go handler observations and float results supply dependencies. Raw Go results, identical source/emitted Node and ASan/UBSan native observations, mutation witnesses and conservative readiness are in REPORT.md and evidence/. No whole rule or independently parsed AST is claimed.
