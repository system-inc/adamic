# Arbitrary values and theme breakpoint registration

Each public helper owns one .a file. value_arena.a declares the type-only adapter for a finite, acyclic ParseValue tree: roots and children index mutable node records, preserving traversal order and in-place value writes. Valid indices and UTF-8-derived text are caller prerequisites. Arbitrary cyclic or aliased Go slice geometries, malformed adapter state and full int64 orders are outside this bounded contract.

recursivelyDecodeArbitraryValues mutates function names and words/separators using an explicit convert callback. It recognizes url and _url suffixes before decoding their names and preserves their entire argument tree. var/theme and their underscore suffixes preserve only a first word's underscores, including unescaping escaped underscores; other arguments recurse normally. Other function names/arguments recurse and unknown node kinds remain untouched. No array geometry or kind is changed.

decodeArbitraryValue converts immediately when input has no left parenthesis, without parsing/writing/math. Otherwise it calls parse on the original input, mutates that returned arena, writes it, then calls math on the written CSS. DecodeDependencies supplies converter, parser, writer and math implementations; only orchestration and the owned walk are ported here. Caller wiring to separately owned helpers remains integration work. Its tests use real Go ParseValue geometry and Go math answers keyed to the exact intermediate CSS, a test-only converter/serializer, and explicit parser-input validation. This does not claim an independent ParseValue, ValueToCss or math implementation.

registerThemeBreakpointVariants accepts the nullable theme as a presence flag and explicit group/keys/has/register callbacks. It returns before dependency calls on nil theme, returns before key enumeration on absent group, requests only --breakpoint, skips empty/already-present names, and registers each remaining name as static at the group's exact order. The register dependency is RegisterFrameworkVariants, not Register's appending-order behavior. Theme KeysInNamespaces, group lookup and registry mutation are separately owned dependencies.

The oracle uses pinned Go's real private helpers, ParseValue, Theme, VariantRegistry and generated group table through temporary owned export overlays. Capture records all six consumers and 157 runtime sources before external-engine guards. 319 text/AST inputs, 96 custom trees and 5,104 breakpoint states produce 5,838 matching lines on Go, source Node, emitted JavaScript and sanitized native. Malformed value strings use Go's actual parser geometry; they are not reparsed independently in Adamic. Math answers and theme keys come from Go and are test-only dependency observations.
