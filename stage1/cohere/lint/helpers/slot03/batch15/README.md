# Control-flow jump stack and unreachable continuation

Each helper has a separate `.a` file. These functions operate on a private builder state, not a complete graph builder or lint rule.

- pushJump appends a fresh target with one labelsOf call on the unchanged node, unchanged break/continue/loop handles, breakable true and broken false. The previous target objects are retained. labelsOf must return the real parser-owned enclosing labels, in Go order.
- popJump removes exactly the final target. Empty stacks violate the private Go precondition and are refused with panic. Go's empty pop also panics. The private jumps slice has no external slice-header aliases in upstream consumers; this port uses a replacement array while preserving earlier object identities. It does not claim general Go backing-store alias semantics.
- makeUnreachable calls newBlock, then appendSuccessor(old, fresh) without propagating incoming reachability. It adds false only to an already-present barrier slice and makes fresh current. The allocator must provide a fresh zero-state block and the append dependency must preserve Go's successor storage. The old block's reachability and incoming flag are untouched.

Opaque node/block identities are integer arena handles; -1 means nil. The barrier slice uses hasCycleBarrier plus cycleBarrier, preserving nil versus present-empty without an unsupported boolean[] | null field. Absent storage values are private and must not be observed separately from the flag. This representation is an adapter contract, not a shared graph model. No new rule listener dispatch or regex is added.

The owned temporary Go overlay leaves all three helper bodies unchanged, wrapping actual invocations before and after real CFG Build calls on every parser root. Snapshots cover labels, target ordering/flags, opaque identity, successors, barrier values and presence, old and new block reachability. Complete runtime sources for all four consumers are parsed by Go. Labels and block allocation remain explicit dependencies. Additional nested-label, jump, switch, abrupt-exit and finally sources plus stack-depth and successor-count/flag combinations exercise boundaries. Source Node, emitted JavaScript and ASan/UBSan native match actual Go on 6,997 operation snapshots. Eleven transition mutants and one empty-stack refusal mutant prove the checks can fail.
