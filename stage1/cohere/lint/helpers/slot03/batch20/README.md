# Slot 03, batch twenty

One reserved helper per .a file. These are backend-neutral helper ports; they do not register rules or implement a complete CFG backend.

- `try_statement.a`: Go `control_flow_graph.(*Builder[E]).tryStatement`. `TryView` names the parsed try block, catch binding/block and finally block. Integer arena handles preserve node/block identity. `TryState.frames` is a readonly arena of mutable frame records, preserving frame identity after popping `stack`. Replacement insertion avoids a cycle-capable mutable arena. Backends implement recursive statement/binding work, graph storage/reachability, fork snapshots and handler selection. They update the same state and frame objects. Allocation occurs before the frame is made visible on the stack, as in Go. `-1` denotes a missing node/block. Direct callback traces include all frame fields, stack IDs, current reachability and block incoming flags.
- `is_document_file.a`: Go `nextjs.IsDocumentFile`. The `splitPath` dependency supplies exactly Go's basename and parent basename. The basename requires `_document.`; the directory form requires only the prefixes `index` and `_document`, including longer names. This intentionally preserves cohere's documented union of upstream predicates.
- `last_separator.a`: Go `nextjs.lastSeparator`. Input is the exact Go string byte sequence. Returning its last slash or backslash position preserves Go byte offsets for both valid and invalid UTF-8; no UTF-16 conversion belongs in this API. An eventual finding adapter must convert offsets at the position boundary. No regex is being replaced or hand matched.

The temporary Go overlay executes unchanged upstream bodies. Parsed metadata and backend callback contracts are prerequisites. No shared harness, registry, compiler, runtime or cohere source file is edited. Tests capture all seven consumer corpora, compare source Node, emitted JavaScript and sanitized native with actual Go, and require every native semantic variant to compile and exit cleanly before an output mismatch counts. `testdata/regenerate.py` reconstructs captured fixtures from real runtime test inputs, including dynamically assembled cases. `readiness.json` reports frozen inventory dependency edges; it does not claim full rule finding/fix/suggestion parity.

Replay consumes one expected callback event per actual callback. An out-of-order callback returns the missing-value sentinel rather than borrowing an unrelated block/frame return value. Its kind, arguments and pre/post state still appear in the independently generated trace and fail exact comparison. This keeps a callback-order mutation from turning into a replay-induced invalid arena index; it does not accept a mismatch.
