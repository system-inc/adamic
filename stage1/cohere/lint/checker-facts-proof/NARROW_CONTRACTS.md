# Narrow checker question contracts

Status: implemented in this working unit; runtime proof results are pending. Every answer is generated by the run's live typescript-go checker. No answer contains a Go lint verdict.

Answers use the existing fields protocol: version `1`, framed question mode, then the fields below. Text lengths are UTF-16 units. Numbers and booleans are canonical decimal fields (`0`/`1` for booleans). Node selectors use exact UTF-8 byte spans and ast.Kind names. Returned declaration spans include leading trivia, exactly as Go's Pos()/End() do.

- `symbol-identity`: present; if present, run-scoped symbol ID. Calls GetSymbolAtLocation. No declarations, no program read.
- `shorthand-value-identity`: present; if present, run-scoped value-symbol ID. Accepts a shorthand property or its identifier child. Calls GetShorthandAssignmentValueSymbol. No declarations, no program read.
- `first-declaration-file`: symbol present; if present, declaration present; if present, first declaration's source IsDeclarationFile. No declaration record, no program read.
- `local-binding-declarations`: symbol present; if present, current-file declaration count; each declaration's kind, byte start, byte end. Uses the shorthand value symbol where needed. Filters by SourceFile identity and preserves compiler declaration order. No foreign records or program read.
- `local-symbol-details`: own symbol present; if present, ID, flags, name, total declaration count, current-file declaration count; each local declaration's kind, byte start, byte end. The total is a scalar, not a foreign declaration record. No program read.
- `alias-target-identity` and `skip-alias-identity`: target present; if present, ID and flags. The first follows GetAliasedSymbol for an alias; the second uses SkipAlias. No declaration records or program read.
- `local-alias-declarations`: target present; if present, flags and current-file declaration count; each local declaration's kind, byte start, byte end. Uses SkipAlias, then filters by current SourceFile identity. No foreign records or program read.
- `output-symbol` with the `files` suffix: own symbol present; if present, total declaration count and each source IsDeclarationFile flag, in compiler order. No paths, declaration records, library query or program read. Legacy no-suffix and `own` forms retain their full wire grammar and require ReadsOtherFiles in the harness.
- `library-member-provenance`: symbol present; if present, declaration count; each declaration's raw IsSourceFileDefaultLibrary result, kind, name, parent kind and parent name. The request is a SourceFile question followed by same-file start, end and kind. Requires ReadsDefaultLibrary alone. No source path/body payload and no compiler-options lookup.
- `symbol-default-library`: one boolean, following cohere checking.IsSymbolFromDefaultLibrary through its default-library and configured-lib fallback. Same-file selector as above. Requires ReadsCompilerOptions and ReadsDefaultLibrary, as its separate reads actually do.
- `resolved-signature`: signature present; if present, return-type run ID and declaration present; if present, declaration path, kind, span, node flags, declaration-file flag, parent kind/name/span, ancestry count and each ancestor kind/name/name-kind. No JSDoc, parameter text, default-library lookup or foreign body. The return ID belongs to the same run's type table.
- `emit-module-kind`: numeric GetEmitModuleKind. Requires ReadsCompilerOptions.
- `symbols-in-scope`: request includes a canonical uint32 meaning; answer contains count and each visible name, symbol ID and exported symbol ID. Native rules decide shadowing and symbol equality.

Full symbol/declaration-body questions remain guarded by ReadsOtherFiles even through askNode. Payloads that also contain default-library membership flags additionally require ReadsDefaultLibrary; plain binding/alias declaration records do not contain that field. Node-level library and options questions also check their own read kinds, preventing an askFile caller from labelling a library request as a different declared kind.

The harness records the exact selector, question and answer per row. Source Node and emitted JavaScript replay the same facts; missing and unasked entries remain failures. The bridge's program handle, type IDs and symbol IDs all have one run lifetime, and fix passes remain syntax-only.

Proving fixtures use no-unassigned-vars, preserve-caught-error and no-promise-executor-return for the prioritized narrow answers. The ISO-date rule isolates library provenance under ReadsDefaultLibrary alone. Qualifier, mock-namespace, symbol-description and valid-typeof consumers exercise the next questions. Direct Go contract tests compare the raw answers with independent checker calls. Source mutants and rule mutants will be reported only after execution.
