# symbol-description on the unified typed harness

This migrates the existing wave-24 claim. The concrete listener receives its descriptor's handed node, uses RuleContext.checker facts, and reports complete findings/suggestions with upstream messages. The Go adapter captures every test beginning with the descriptor's upstreamTest prefix and decodes options independently.

The current full-package runtime agreement, witness, mutant, timing evidence and limits are documented in [the wave report](../symbol-description/LANDING_REPORT.md). No new rule is claimed.
