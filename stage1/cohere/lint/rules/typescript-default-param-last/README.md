# @typescript-eslint/default-param-last

The listener visits functions, arrows, methods, constructors and accessors with
bodies. It identifies the last required parameter, then reports each preceding
defaulted or optional parameter, preserving modifier-inclusive spans. A rest
parameter is neither required nor reportable. Bodyless signatures are exempt.
There is no fix or option surface. All implementation and message files are .a.

The parser does not retain an initializer's equals token as a child. The port
scans the gap before the final child for that token, ignoring comments and type
parameter defaults. The independent oracle is cohere's unchanged
typescript.DefaultParamLast. The optional_parameter_ignored mutant removes only
the optional-parameter classification and loses its finding on source Node,
emitted JavaScript and sanitized native after successful compilation/execution.

The continuation report at ../../claims/wave1-15-next-report.md records evidence
and default registration limits. Compatibility is proposed in the neighboring
Tailwind directory and applied only through a scratch Go overlay.
