Non-null assertions

This `.a` candidate reports every NonNullExpression. It offers optional-chain suggestions only for object/callee positions and reproduces Go's assignment-target recursion, question-dot handling, two-edit dot repair, and raw forward dot search. Every suggestion retains its ID, description, all edit ranges and replacement text as typed data. Definite assignment tokens never enter the listener. The message is copied byte for byte from Go cohere's policy catalog.

The owned `SuggestedFinding` extends the existing Finding with an immutable list of suggestions and their edits. The regular driver cannot report those fields, so the factory refuses when this rule is selected without the detailed reporter. `driver.a` enables and emits complete suggestion metadata. `oracle-detailed.go.txt` runs the unmodified Go rules and renders their actual diagnostics and fixes, without changing or normalizing a Go rule. Witness/upstream manifests also apply each suggestion independently and compare resulting bytes. Compiler manifests compare complete edits without repeatedly printing an entire compiler file for every suggestion. Automatic fixes are applied only through Go's actual fix engine; neither new assertion rule has an automatic fix.

The Unicode witness contains a dot inside an intervening comment. Go's raw dot search edits that dot; this candidate preserves the measured behavior. The semantic mutant drops optional-chain suggestions. All three runtimes compile and exit cleanly, and only output comparison catches the missing edits.

The checked-in preparation script reads shared Go sources and patches temporary copies only. It never changes the shared generator or test harness in the repository. Its private test filter covers these three candidates and adds the upstream absent-optional-node tests. See REPORT.md for exact commands, outputs and integration blockers. Shared `.a` support is being handled on codex/lint-harness-dot-a; the separate multi-range suggestion-reporting limitation remains.
