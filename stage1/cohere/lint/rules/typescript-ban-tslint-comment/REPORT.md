# @typescript-eslint/ban-tslint-comment

Recognizes Go ASCII-regexp whitespace and directive boundaries, preserves Unicode trimming, and records the widened whitespace edit separately from the comment diagnostic.

Implementation is `rule.a`; `rule.json` registers through the directory contract. `oracle.go` calls the unchanged Go cohere rule. `mutant.json` owns `tslint_directive_disabled`. The mutant compiled and ran successfully and was caught by output comparison on source Node, emitted JavaScript and ASan/UBSan native.
