# Parked rules outside registry discovery

These directories retain their source and evidence, but are nested below an owned rule directory so the registry's rules/*/rule.json discovery does not register them.

- `@typescript-eslint/no-empty-object-type`: dynamic RegExp lowering refuses an options-derived pattern. Reproducer: enable this rule with `{"AllowWithName":"Allowed"}` on `interface Blocked {}` and compile its registered driver to native. The rule constructs `new RegExp(pattern, 'u')`; stage 0 refuses a nonconstant pattern. Restore the directory to `rules/typescript-no-empty-object-type` after the runtime regex compiler lands, then rerun parity.
- `@typescript-eslint/no-import-type-side-effects`: the unified Go oracle accepts only one automatic edit, whereas this rule reports several. Reproducer: select this rule on `import { type A } from 'mod';`. The oracle panics at testdata/oracle.go with `unexpected fix shape`. `/tmp/wave109-owned3.log` captures TestOwnedWitnesses failing on this gap. Restore to `rules/typescript-no-import-type-side-effects` when shared multiple-edit serialization is supported; no oracle guard was relaxed.

Landing retains no-dupe-class-members and react/no-invalid-html-attribute. The shared harness files were not edited.
- `react/jsx-no-useless-fragment`: shared fixed-source reparse loses the JSX script kind. Reproducer: `const a = <div><><span /></></div>;` in a `.tsx` file. The fragment fix leaves `const a = <div><span /></div>;`, but lint.ts constructs `new Parser(result, 'fixed source')`; Node refuses with `parser slice expected GreaterThanToken, got SlashToken at 21 in fixed source`. TestOwnedWitnesses logs this in `wave109-owned5.log`. Restore the directory after the shared fixer preserves the script kind.
- `react/no-unescaped-entities`: upstream option capture serializes the decoded `NoUnescapedEntitiesOptions` rather than its original JSON. `Forbid` points to private `forbiddenEntity` fields; `json.Marshal` turns an entry into `{}`, losing the character, alternatives, and their presence flag. Reproducer: decode `{"forbid":["&"]}` with upstream `DecodeNoUnescapedEntitiesOptions`, then JSON-marshal the resulting options: `{"Forbid":[{}]}`. Feeding that captured field 5 back to the decoder first refuses the uppercase key (`option "Forbid" is spelled "forbid"`); changing its case cannot restore the missing entry. TestRulesAgree records the failure in `wave109-landing-passing-final.log`; the separate Go reproducer output is `wave109-private-options-probe.log`. This needs shared capture to retain original options; no private-field reconstruction or weakened decoder is used.
