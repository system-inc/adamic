# Type-aware lint slice boundaries

Sixteen default-option production rules are ported to native Adamic judgment
code. Compiler facts come from the explicitly linked external TypeScript Go
checker; this does not port that checker or add a collector to Adamic.
Generated controls and the frozen 77-file compiler and 287-file repository
corpora compare complete finding, fix and suggestion bytes against unchanged
production Go rules, with sanitizer and mutant checks.

General rule options, CLI configuration, suppression and the edit engine are
not integrated. The unbound-method rule explicitly refuses `noImplicitThis:
false`. Parser and nominal representation limits remain; this is not all of
Cohere's type-aware rules. The reports record the precise tested questions,
populations and unsupported boundaries.

The progress inventory marks the upstream TypeScript rule package partial.
It gives these mixed source files no whole-file or whole-function line credit
until their corresponding source boundaries are separately reviewed.
