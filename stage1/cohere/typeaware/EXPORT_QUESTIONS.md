# Wave 13 checker facts

The two operations use ABI version 1's existing `tsgo_inspect`, exact kind and
UTF-8 byte span lookup, program-scoped ownership, and owned result buffers.
Each result field has a decimal UTF-16 length followed by LF and its text.
Numbers and booleans use the existing checked canonical framing. The Adamic
consumer validates the version, operation, lengths, numeric fields and end of
frame before interpreting facts. No Go operation returns a finding or an edit.

`export-symbol-chain`, implemented in `export_symbol_chain.go` and decoded in
`export_symbol_chain.a`, accepts an identifier or string name with no suffix.
Its fields are version 1, operation name, and symbol count. Each symbol has its
raw flags and declaration count. Each declaration has its kind, direct
`IsTypeOnly()` flag, ancestor count, then each ancestor's kind and direct
`IsTypeOnly()` flag. Ancestors stop at SourceFile. The chain starts with
GetSymbolAtLocation and follows SkipAlias to a different symbol; repeated
identities stop the walk. An absent symbol gives a zero count. Adamic implements
the production rule's declaration/ancestor tests, value flag test and alias
interpretation.

`export-module-properties`, implemented in `export_module_properties.go` and
decoded in `export_module_properties.a`, accepts a string module specifier with
no suffix. Fields are version 1, operation name, symbol-present flag and, when
present, type-present flag. A present type has a property count followed by each
property's valid UTF-8 display name and whether getPropertyOfType finds the
original key. Lookup uses the original key before UTF-8 display normalization.
Adamic decides whether any lookup represents a runtime export and selects the
report and insertion position. This reproduces the production Go rule's paired
property enumeration/lookup behavior for type-only star exports.

Direct checker tests cover alias and terminal flags, interface declaration
syntax, module properties, malformed suffixes and inappropriate node kinds.
Compiled mutants for both questions must exit normally with empty stderr and
change complete diagnostic bytes relative to independent production Go cohere.
The suite also rejects released handles with panic 70 and exercises that
expectation with the existing archive registry retention mutant.

All new executable Adamic sources use `.a`. Deliberately invalid TypeScript
subjects are generated by Go tests; cross-file helper fixtures use `.ts` and
`.js` imports so this pinned TypeScript module resolver resolves them. Explicit
`.a` roots are loaded on both sides. Changing how that checker resolves `.a`
imports is outside this rule port.
