# Archived timeout implementation and independent evidence

The timeout rule implements default-library Promise.race and Promise constructor
recognition, same-file const promise references, global timer declaration ancestry,
executor-only traversal, dropped expression/void handles, and plain binding reads
through checker identities, including shorthand properties and shadowing.
Findings, positions and wording are constructed in Adamic. The production rule
has no fixes or suggestions; complete fields, including their zero counts, match.

The raw declaration-ancestry question lives in its own Go file and its own Adamic
decoder. It returns symbol identity and declaration/file/ancestor facts, including
external-module and global-augmentation flags. It contains no cohere rule import,
lint decision, message or repair. An isolated Python validation script adds its
single dispatch entry through a temporary Go overlay. The repository's shared
checker dispatch, registration generator and test harness are untouched. The
question is not registered in the normal production archive.

The independent Go oracle loads its own compiler program and invokes the pinned,
unmodified production rule through its registry. It imports no bridge code.
Root declaration files are retained. Both runners use the pinned corpus and
frozen manifests from the original wave; corpus roots have not been expanded to
include the new experiment.

# Partial implementations and exact blockers

The archived process-exit module contains minimal write-chain state reduction,
catch-entry forgetting, a graph worklist evaluator and production wording. Its
state reducer matches the real private Go cohere state methods over 2560 cases,
12164 bytes, normal and native sanitizers. The Go oracle exposes those existing
private methods through an isolated package overlay, without copying their logic.
Only state reduction was exercised; the graph evaluator was not exercised as a
complete source-to-findings rule.

The process-exit rule is incomplete: this branch has no native equivalent of
cohere's control_flow_graph.Build/RootOf with expression and statement hooks,
throw edges, catch markers, labelled break/continue and finally duplication.
The existing completion.ts computes completion sets and is not that graph.
Resolved callee declaration bodies, generator/async flags and cross-file bodies
also need a raw adapter. Source-order scanning is not a replacement for those
semantics. An explicit refusal function is saved, but its refusal was not run
because validation stopped earlier.

The archived blocking-stream module contains reverse import-closure propagation,
entry selection and exact message rendering. It is unvalidated and incomplete:
it needs whole-program source files and resolved module edges, computed-load facts,
callee metadata, transitive blocking analysis and the same native CFG construction.
The normal bridge has no question supplying that whole-program graph. The saved
index oracle and fixtures are preparatory code, not passing evidence. No
blocking-stream rule mutant was run and no complete findings agreement is claimed.

The partial validation's emitted-JavaScript build succeeded for the process state
probe. Node then failed with ERR_MODULE_NOT_FOUND for the generated program's
`adamic` package import. A Node runtime binding was not installed by this isolated
script. The script halted there, before the blocking-stream tests. The untouched
shared harness owner is adding .a/profile/suggestion support; no shared harness
or registration work was taken over to bypass the missing integration.

The timeout runner's emitted JavaScript was not tested: this branch's CLI
explicitly refuses JavaScript programs that use the external tsgo native library.
The archived timeout question also needs integration by the checker dispatch owner;
it currently works only through the validation overlay. This is why the archive
is experimental work rather than a production-ready continuation delivery.
