Both adapters use the existing exact-kind/span inspect ABI and length-framed fields. Symbol/type identities are program-local borrowed handles, invalid after release. No Go question returns a lint verdict. Their registration changes are one line each in facts.go. Native imports the dedicated .a adapters directly.

`binding-state` accepts only an Identifier and no suffix. After version and mode it returns the binding symbol identity/flags, alias-normalized identity, and two declaration records (original and resolved). A record begins with presence; if present it contains source filename, kind, byte bounds, const-variable flag, parent kind and parent byte bounds. Shorthand assignment identifiers use the compiler's value-symbol accessor. Missing symbols produce zero identities and absent records.

`type-operations\noperation\nidentity` accepts canonical unsigned decimal identities. Node operations raw/constrained/contextual/heritage/access-name require identity zero. Argument uses an argument index. Existing-type operations use a live nonzero type identity: apparent/bases/property/member/iterator/signatures/construct/metadata. Property/member carry one additional name field. Unknown operations, missing/extra fields, noncanonical IDs, wrong node kinds and unavailable argument indexes are refused.

All successful operations append a version-1 type-operations shape graph using the existing graph serializer. Access-name prefixes presence/name. Iterator prefixes property-presence. Signatures/construct prefix signature count and, per signature, return identity and parameter count, then parameter identity/rest pairs. Metadata prefixes object flags, property count, construct signature count, symbol identity, a reserved empty field, symbol name/flags, value-declaration kind and declaration count. Each declaration contains kind/file/declaration-file/default-library/node-flags/construct-count, member count with kind/modifier-flags/name-kind tuples, then decorator count with resolved decorator declaration-origin records (file/declaration-file/node-flags). Native applies Promise, iterable, copyability, void-return and inheritance judgments.

The direct checker metadata assertion excludes only ObjectFlagsMembersResolved from its independently leased type, retaining every semantic flag.
