# declared-call-signature

ABI-v1 `tsgoInspect` question on an exact CallExpression or NewExpression. No suffix.
Fields: version 1, mode, presence of a resolved target with declared type parameters.
When present: declared type-parameter identities, declared parameter identities,
instantiated parameter identities (each a count plus identities), declared rest flag,
declared return identity, and contextual call-type identity (zero means absent).
All identities are live per-program checker types usable with the existing
reference-shape questions. No lint judgment, contextual path walk, finding or repair
is performed in Go. Adamic records the container steps, selects stand-ins and
judges promise demand. Unknown suffixes and non-call nodes refuse explicitly.
